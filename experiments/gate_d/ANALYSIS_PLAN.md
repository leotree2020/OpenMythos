# Gate D 分析计划：证据评级的具体规则（在任何正式诊断之前提交）

本文件把预注册第 8.9、9.4 节的证据评级，落实为可以机械执行的规则（`analyze.py`）。它不改变任何指标、阈值或数据，只把预注册中已有的判定组合起来。凡是预注册没有写明、需要实现时确定的细节，都列在第 3 节。

## 1. 每个种子、每一类诊断的结果

只用第 12,000 步的模型状态。每一类诊断给出四种结果之一：**支持**、**反对**、**不确定**、**不适用**。

"读出位置的记录点"指 D2 探针在位置 18 读取的记录点，**不含 `emb`**：
- Transformer：`out0`、`out1`、`out2`
- OpenMythos：`e`、`h1`–`h4`、`h_out`、`coda_out`

其中 ACT 未执行的轮次被跳过。

"检测到 / 未检测到"沿用预注册 8.4 节的线性探针判定。线性探针为"未检测到"、而 MLP 补充探针为"检测到"的记录点，算作"不确定"。

| 假设 | 诊断类 | 支持 | 反对 |
|---|---|---|---|
| H1 查询信息没有到达读出位置 | D2 | 所有读出位置记录点的 P1 都是"未检测到" | 任一读出位置记录点的 P1 为"检测到" |
| | D4 | I0 总效应可忽略（平均 TV < 0.02，或数值上无法区分），且所有 I2 接口都可忽略 | 任一 I2 接口的平均 TV ≥ 0.02 |
| H2 变量—值没有绑定 | D2 | 所有非 `emb` 记录点的 P2 都是"未检测到" | 任一非 `emb` 记录点的 P2 为"检测到" |
| H3 匹配步骤没有形成 | D2 | 所有读出位置记录点的 P3 都是"未检测到" | 任一读出位置记录点的 P3 为"检测到" |
| | D3 | 主统计量判定为"未检测到" | 判定为"检测到按查询定向的注意力" |
| H4 信息存在但没有被读出使用 | D2 | 某个读出位置记录点 X 的 P1 或 P3 为"检测到"（否则整条假设记为"不适用"） | — |
| | D4 | 在 X 上做 I2 替换（位置 18）的效应可忽略 | 该替换的平均 TV ≥ 0.02 |
| H5 当前梯度主要强化四选一，匹配方向信号弱 | D5(c) | `total` 组 d·∇J 的置信区间包含 0，或上限 < 0 | 下限 > 0 |
| | D5(b) | O 方案沿 u 的信噪比的绝对值 < 1 | 信噪比 ≥ 1 |
| H6 成对监督能降低匹配相关参数上的梯度噪声 | D5(b) | `attn_all` 组实测 tr Var(G_P) − tr Var(G_O) 的置信区间上限 < 0 | 下限 > 0 |
| | D5(a) | `attn_all` 组 S − 3V_b 的置信区间下限 > 0 | 上限 < 0 |

两项条件都不满足的，记为"不确定"。

**各类诊断必须通过的对照**（不通过时，该类结果记为"不确定"，并在报告中写明原因）：

| 诊断类 | 对照 |
|---|---|
| D2 | P0 正对照 ≥ 95%；植入信号对照中，P1 和 P2 都在某个 α ≤ 0.5 时被检出 |
| D3 | D0 修订 3 中的注意力重建和"未来权重为 0"两项都通过 |
| D4 | 同源替换和完整状态替换都通过（不通过时诊断已经中止） |
| D5 | `synthetic_d5` 验证通过；共享权重分解检查通过。H6 还需要 `attn_all` 和 `total` 两组的"实测 vs 预测"置信区间重叠 |

## 2. 汇总成证据等级

**每个种子**：
- 只要有一类诊断"支持"、没有任何一类"反对"，该种子记为**支持**；
- 只要有一类"反对"、没有任何一类"支持"，记为**反对**；
- 其他情况记为**不确定**。
- 同时记下支持该方向的诊断类数目。

**每种架构**（每个假设单独评级，按预注册 9.4 节）：

| 等级 | 条件 |
|---|---|
| **强** | 3/3 个种子方向相同，并且每个种子都有 ≥ 2 类诊断支持该方向 |
| **中** | 3/3 个种子方向相同，但不满足"每个种子 ≥ 2 类诊断"；或者 2/3 个种子方向相同，且这两个种子各有 ≥ 2 类诊断支持 |
| **弱或不确定** | 其他情况 |

等级与方向一起报告，例如"强（支持）"或"中（反对）"。

**跨架构**按 9.4 节判定：
- 两组都是"强"且方向相同 → 两种架构共同存在的问题；
- 一组为"强"，另一组为"强"但方向相反，或者为"弱或不确定" → 架构差异线索；
- 其他情况 → 分别报告。

**一条结构性限制，事先说明**：H2 只有 D2 一类诊断，按规则最高只能评为"中"。D4 在查询总效应接近 0 时，无法区分 H1、H2、H3，所以它只作为 H1 和 H4 的诊断类。

## 3. 实现时确定的细节（预注册没有写明，在看到结果之前固定）

- **D2**
  - 某个记录点上，如果 ACT 实际执行该轮的题面不足一半（fit 或 eval 任一），这个记录点就跳过，记为"轮次未执行"。
  - P2 每个题面只取第一道题的那一份（位置 < 17 与查询无关）。
  - 打乱标签对照只做一次（种子固定）。
  - MLP 补充探针的控制，除预注册写明的 P1、P3（位置 18 的 `emb`）外，P2 也加一个同类控制：用 `emb` 记录点数字位置上的特征，MLP 也必须处在基线水平。
- **D3**：ACT 实际执行该轮的题目不足一半时，该循环轮次不计入主统计量，也不计入零分布。
- **D4**
  - 每道题 q 配对同一题面的下一条语句 q'（按语句序号循环）。共 2000 对，每 125 个题面计算一批。
  - 循环轮次的接口只统计该轮实际执行的题目；不足一半时跳过。
  - 噪声下限：同一批题按"整批"和"每批 4 题"各计算一次，两次结果之间各指标的最大差值。
- **D5**
  - (c) 的 ∇K、∇L_roots、∇L_within 和期望下降方向 d 都在 pool_c 上计算，∇J 在 diag_fit 上计算。d·∇J 和 d·∇K 的置信区间按 pool_c 的题面做自助法，计算时把 ∇J、∇K 视为固定向量。
  - (a) 为了计算 Gram 矩阵，暂时在内存中保存每个题面的平均梯度（500 × 参数数），算完即释放；单题梯度不保存。
  - (b) 预测值的置信区间与实测值的置信区间相互独立地估计；"P − O"的置信区间通过两者各自的自助样本相减得到。
- **性能测试数据**：从 Random(50000) 按正式规模（500 + 500 个题面、pool_b 形状的 batch、1000 个 pool_c 题面）临时生成，只用于计时，不产生任何结论。OpenMythos 的 D5 时间按实际执行的循环数放大，估计为 (2 + 4) / (2 + L) 倍。
- **正式运行**
  - 每个状态开始前，核对参数哈希与 D0 修订 3 的记录一致。
  - 4 个进程并行，每个单线程。任一状态出现完整性失败（退出码 3）或其他错误，就结束其余进程、停止，不做分析。
  - 结果目录不为空时拒绝启动。

## 4. 正式诊断前的实现修正（按 8a2bc7d 的启动前审核；不改变任何假设、阈值或已冻结的数据）

1. **D3 零分布改为按题面置换**：每次置换中，每个题面抽一个非零循环偏移（1、2 或 3），同时作用于该题面的 4 道题。这样同一题面的 4 道题恰好构成语句的一个完整排列，且没有一道题保留原语句。原实现对 2000 道题逐题独立抽取，与第 8.5 节"在题面层面"的规定不一致。
2. **D5(b) 的自助法种子按方案分开**：O、P、F 分别固定为 21、22、23（沿 u 投影的自助法用 1021、1022、1023）。这样 P − O、F − O 的置信区间来自相互独立的重抽样。原实现三个方案都用同一个种子。合成验证另外检查了独立重抽样下 P − O 的置信区间是否包含解析值。
3. **D4 相对效应的分母保护**：只有当 I0 总效应的平均 logit 差不为 0，且其绝对值大于 10ε（按第 10.3 节的数值噪声下限）时，才报告相对效应；否则记为"无法稳定估计"。绝对的 logit、概率和 TV 指标照常报告。

回归测试：`regression_tests.py` → `validation/regression_fixes.json`。重新运行的合成验证：`validation/synthetic_d5.json`。

## 5. 修订 4（待审核，见 PREREGISTRATION 第 11 节）

- D2、D3、D4 的 OpenMythos 循环记录点，改为只使用完整题面（4 道题都执行了该轮），不足一半就跳过。这一条取代第 3 节中"按题目数计一半"的规则。
- D3 的"判定"改为：随机化 p 值 ≤ 0.05（循环偏移在 {0, 1, 2, 3} 上均匀，取跨层、跨头的最大值），并且统计量 ≥ 0.5。第 4 节第 1 条中的"非零偏移"零分布只作描述性参照。
- H3 的 D3 诊断类仍然只读"判定"字段，第 1 节的映射不变。
