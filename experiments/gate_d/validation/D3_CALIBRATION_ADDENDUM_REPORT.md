## 解释与限制

1. **B3′**
   - 按预注册标准通过：Wilson 下限 3.7% ≤ 5%。
   - 但 p ≤ 0.05 的实测比例是 **5.5%**，略高于 5%，置信区间上限为 8.2%。所以只能说，在这些模拟条件下，没有检测到假阳性率显著超标；**不能**说误报率已经被证明 ≤ 5%。
   - 完整判定的触发率为 0，因为在原假设下统计量远低于 0.5 这一门槛。
   - 同样的数据下，53e5492 的检验 400/400 都"超过参照"，说明那次修订针对的选择偏差确实存在，而且当时的检验无法纠正它。
2. **C′**：当循环层的完整题面充足时，检验对植入的匹配信号检出率为 100/100。
3. **原 C 仍然是"未通过"，不改写**。它说明：完整题面不足一半的循环轮次完全不受 D3 检验，其中即使有真实信号也测不到。这是 D3 的检测范围限制，**不能**写成"模型在这些层中没有信号"。正式诊断报告中，被排除的轮次会逐一列出。
4. 两次校准回答的是不同的问题，结果都保留。
