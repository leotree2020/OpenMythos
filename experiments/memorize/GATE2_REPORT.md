## 3. MoE 专家梯度与路由

**梯度状态**（3000 步中出现 `none` / `zero` 的步数；其余步数都是 `nonzero`）：

| 组 | 种子 | 结果 |
|---|---|---|
| OpenMythos | 1 | 专家 1：39 步 `none`，**1 步 `zero`**；专家 3：23 步 `none` |
| OpenMythos | 2 | 专家 1：51 步 `none`；专家 2：39 步 `none` |
| OpenMythos | 3 | 专家 1：4 步；专家 2：5 步；专家 3：14 步 `none` |
| Transformer | 1–3 | 全部 3000 步都是 `nonzero` |

只有 OpenMythos 种子一的专家 1 出现过 1 次 `zero`，即参与了计算但梯度为 0。`none` 只占全部步数的 0.1%–1.7%。没有任何专家长期得不到梯度。

**路由选中占比**（每个 token 选 2 个专家，全程累计）：

| 组 | 种子 | 专家 0 / 1 / 2 / 3 |
|---|---|---|
| OpenMythos | 1 | 第 1 轮 39.6 / **6.1** / 14.1 / 40.2；第 4 轮 25.9 / 11.9 / 19.6 / 42.6 |
| OpenMythos | 2 | 第 1 轮 43.5 / **11.3** / 19.3 / 25.9；第 4 轮 44.5 / 10.3 / 19.4 / 25.9 |
| OpenMythos | 3 | 第 1 轮 25.2 / **10.1** / 20.8 / 43.9；第 4 轮 21.3 / 9.3 / 21.8 / 47.6 |
| Transformer | 1 | 24.5 / 26.8 / 23.3 / 25.4 |
| Transformer | 2 | 27.9 / 23.4 / 24.2 / 24.4 |
| Transformer | 3 | 24.6 / 26.1 / 22.0 / 27.3 |

- 和 Gate 1 一样，OpenMythos 的路由明显不均衡：每个种子都有一个专家的使用率只有约 6%–12%，另有一个专家接近 40%–48%。Transformer 的四个专家都在 22%–28% 之间。
- 两组的负载均衡偏置 `router_bias` 始终为 0。
- 不均衡的路由没有妨碍 OpenMythos 记住 512 题。它对泛化能力有没有影响，目前没有证据。

**OpenMythos 实际执行的循环轮数**（由各轮被路由的 token 数推出）：第 1、2 轮在每次前向中都执行；第 3、4 轮只在部分前向中执行（例如种子一的第 4 轮约占 36%），所以各种子的计算量不同（32.2M–37.0M）。

**和 Gate 1 对比**：

| | Gate 1（32 题） | Gate 2（512 题） |
|---|---|---|
| 留出集准确率 | 9.6%–12.2%（≈ 均匀猜 0–9） | 26.6%–31.0%（≈ 在根数字里随机猜） |
| 留出集落在根数字内 | 33.6%–42.8%（≈ 均匀猜 0–9） | 90.4%–96.0% |

- 题量从 32 增加到 512 后，两组模型在**新题**上都学会了"答案是题面中的某个根数字"，但仍然没有学会"是哪一个"：准确率等于在根数字里随机猜的水平。
- 这和第一轮 Basic Learn 的表现一致：在不断生成新题的训练下，两组也停在同样的水平。
- 落在根数字内的比例只说明模型把答案限制在了候选集合里，不说明它在追踪链条。

## 6. 对核心问题的阶段性回答

> Mini-Mythos 究竟是缺乏学习链式关系的能力，还是当前训练方法根本没有让它有效学习？

| 已经确认 | 证据 |
|---|---|
| 训练管道、loss 位置、标签映射、梯度、优化器都能有效更新参数 | Gate 1、Gate 2 共 12/12 个种子在固定题上全部答对 |
| 两组都有足够容量记住 512 道题 | Gate 2，6/6 个种子 |
| 在记忆能力上，OpenMythos 没有表现出优势 | 记住的速度相近或略慢，计算量多约 70% |
| 题量增加后，两组都学到了"答案在根数字里"这条表面规律 | 留出集上落在根数字内的比例从 34%–43% 升到 90%–96% |
| 两组都**没有**学到链式追踪规则 | 留出集准确率 ≈ 在根数字里随机猜（29%） |

| 还不能确定 | 原因 |
|---|---|
| 是模型缺乏学习链式关系的能力，还是需要更多数据、更多步数或不同的训练方式 | 本轮只测记忆，没有改变训练条件；512 题可以靠记忆完成，不需要学会规则 |
| OpenMythos 的循环和 MoE 路由不均衡是否影响泛化 | 两组在记忆和泛化上的表现都没有差别 |

**目前能下的结论**：第一轮 Basic Learn 的失败**不是**因为训练管道失效或模型容量不足，而是因为在当前的数据量和训练方式下，两组模型都只学到了"答案在根数字里"这条表面规律，没有学到"沿着赋值链找答案"的规则。这个问题两组都存在，与是否使用循环架构无关。
