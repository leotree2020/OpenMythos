## 3. MoE 专家梯度与路由

每个 token 选 2 个专家，所以一个专家的"选中占比"约 48% 时，表示几乎所有 token 都选了它；约 1% 时，表示几乎没有 token 选它。

**梯度状态**（2000 步中出现 `none` / `zero` / `nonzero` 的步数）：

| 组 | 种子 | 结果 |
|---|---|---|
| OpenMythos | 1 | 专家 1 有 14 步、专家 3 有 20 步为 `none`（这一步没被路由到），其余各步都是 `nonzero` |
| OpenMythos | 2 | 专家 1 有 8 步为 `none` |
| OpenMythos | 3 | 专家 3 有 8 步为 `none` |
| Transformer | 1–3 | 2000 步全部为 `nonzero` |
| 两组 | 全部 | 没有出现 `zero`（参与了计算但梯度为 0 的情况） |

这些 `none` 都只出现在训练初期的个别步骤里，没有任何专家长期得不到梯度。

**路由选中占比**（全程累计；OpenMythos 按循环轮次分开）：

| 组 | 种子 | 专家 0 / 1 / 2 / 3 |
|---|---|---|
| OpenMythos | 1 | 第 1 轮 15.8 / 48.4 / **1.3** / 34.6；第 4 轮 3.7 / 48.7 / **1.8** / 45.9 |
| OpenMythos | 2 | 第 1 轮 26.1 / 43.3 / 16.4 / 14.3；第 4 轮 32.8 / 37.8 / 16.4 / 13.1 |
| OpenMythos | 3 | 第 1 轮 **1.0** / 25.0 / 48.7 / 25.3；第 2 轮 **0.8** / 23.0 / 48.1 / 28.2 |
| Transformer | 1 | 19.6 / 27.2 / 23.2 / 30.0 |
| Transformer | 2 | 22.4 / 27.7 / 16.8 / 33.1 |
| Transformer | 3 | 16.9 / 26.5 / 29.9 / 26.7 |

- **OpenMythos 种子一、种子三各有一个专家几乎不被使用**（约 1% 的选中占比），并且各有一个专家几乎被所有 token 选中（约 48%）。Transformer 的分配比较均匀，最低的专家也有 16.8%。
- 两组的负载均衡偏置 `router_bias` 最终都是 [0, 0, 0, 0]，也就是负载均衡从未生效。
- 这些是观察到的现象。它们是否影响学习能力，目前不能下结论，因为两组都完成了记忆任务。

**OpenMythos 实际执行的循环轮数**：种子一、种子二在整个训练中每次都跑满 4 轮；种子三的第 3 轮只在约 28% 的前向调用里执行（127 万 / 448 万 token），第 4 轮几乎不执行，所以它的计算量更低（9.62M 对 13.42M）。

## 5. "预测是否落在根数字集合内"（单独报告，不替代准确率）

| | OpenMythos 种子 1 / 2 / 3 | Transformer 种子 1 / 2 / 3 |
|---|---|---|
| 固定 32 题：准确率 | 100% / 100% / 100% | 100% / 100% / 100% |
| 固定 32 题：落在根数字内 | 100% / 100% / 100% | 100% / 100% / 100% |
| 新的留出集（500 道 1 跳题，仅参考）：准确率 | 10.8% / 9.6% / 9.6% | 12.2% / 12.0% / 12.0% |
| 新的留出集：落在根数字内 | 42.6% / 33.6% / 39.2% | 42.8% / 42.8% / 41.8% |

对照你给的三种情况：
- 固定题集是"准确率 100%，根数字命中率 100%"，属于"固定题已全部答对，但不代表能推理新题"。
- 在新题上，准确率约 10%，接近**均匀随机猜 10 个数字**的水平，而不是"在根数字里随机猜"的 29%。根数字命中率只有 34%–43%，大致相当于从 0–9 里随便选一个数字时碰巧落在根数字里的概率（每题有 3–4 个根数字，即 30%–40%）。
- 也就是说，两组模型都把这 32 道题**当成了查表**：在新题上，它们既没有按链条找答案，也没有把答案限制在题面的根数字里。

## 6. 对核心问题的阶段性回答

> Mini-Mythos 究竟是缺乏学习链式关系的能力，还是当前训练方法根本没有让它有效学习？

Gate 1 能回答的部分：
- **训练管道、loss 位置、标签映射、梯度传播、优化器都是正常的。** 两组都能在约 100 步内把 32 道题完全记住，数据全程没有变化。所以第一轮"学不会"的原因，**不是**实现或优化器无法更新参数。这排除了你列出的第一行情况（"连 32 题都记不住"）。
- 在记忆能力上，OpenMythos 和 Transformer 没有实质差别。Transformer 在前 50 步稍快，而 OpenMythos 多用了 1.8 倍计算量。

Gate 1 不能回答的部分：
- 模型能否学会**规则**。32 题完全可以靠查表记住，所以本轮无法区分"能力不足"和"训练方法没让它学规则"。留出集上约 10% 的准确率说明，目前两组都只学会了查表。
