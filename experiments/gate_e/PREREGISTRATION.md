## 0. 研究问题与范围

**主问题**（按 Gate D 最终审核确定）：为什么训练让变量信息变得难以读取，同时模型迅速收敛到不依赖查询的"在根数字里选一个"策略？

Gate D 给出的出发点：
- 以下都是探索性数据，不是已证实的结论。
- 第 0 步，数字位置上的变量字母能以 53%–66% 的准确率被线性读出。
- 第 3000 步，降到 4%–26%；第 12,000 步，降到 2%–15%。
- 同期 MLP 探针仍有 9.6%–34.5%，随机水平为 1.9%。所以目前只能说"变得难以线性读取"，不能说"被删除"。
- "选根"在前 3000 步内形成，同时梯度形态发生转变：同一题面不同查询的梯度余弦从约 0 变为 −0.33。

## 1. 任务

### 1.1 两变量直接查值（K=2）

- 格式：`a=3;b=7;|b?` → `7`。
- 生成方式：由 `gen_gate_a/levels.py` 的 `_chains_prompt(rng, [1, 1])` 生成（import 使用，不修改），与 A 级相同：
  - 2 个不同的变量字母，2 个不同的根数字；
  - 语句顺序随机，查询的变量在两条语句中均匀分布。
- 位置：
  - 字母在 0、4，`=` 在 1、5，数字在 2、6；
  - 查询字母在 9，读出位置 `?` 在 10；
  - 输入长 11，答案在第 11 位。
- 模型：`build(arm, 2)`，即 `task_cfg(4, 2)`，max_seq_len = 12。
  - 参数量与 K=4 相同：OpenMythos 609,698，Transformer 607,104。
  - 已核实：同一种子下，K=2 与 K=4 的全部可训练参数初始值逐位相同。OpenMythos 只有 RoPE 预计算缓冲区（`freqs_cis`、`freqs_cis_mla`）因长度不同而不同；实现时核对两者的前 12 行逐位相同。
  - 所以同一种子下，K=2 和 K=4 的运行从同一个初始化出发，可以按种子配对比较。
- 随机水平：在根数字里随机猜为 50%。
- 不看查询的猜法：在同一批题上计算以下几种，取其中最强的作为基线：随机猜、第一条语句的数字、最后一条语句的数字、较大的根、较小的根。
- 模型自身的"数字偏好"规则只作描述，沿用 Gate D D1 的定义（`d1.digit_preference`：在拟合集上估计 P(预测 = d | d 是根)，选偏好最高的根）。它是从模型预测中估计的，不作为不看查询的基线。

### 1.2 为什么需要留出题面

K=2 的题目空间很小：
- 有序字母对 52×51，有序数字对 10×9，共 238,680 个题面，477,360 道题。
- 12,000 步 × 64 题 = 768,000 次抽样，约 80% 的题会在训练中出现。
- 如果不留出，开发集、测试集上的准确率无法区分"学会规则"和"记住了题"。

**留出方式**：
- 以题面中两条语句构成的无序集合，例如 {(a,3), (b,7)}，作为键。
- 键的 sha256 对 10 取余为 0 的题面留出，约占 10%。两种语句顺序和两个查询都一起留出。
- 训练时遇到留出题面就重新抽样。
- 开发集、测试集、诊断集都只从留出题面中抽取，所以训练中**不可能**见过这些题。
- D5 型梯度测量（M5）估计的是训练分布下的梯度，所以它的题池从非留出题面中抽取。

### M2 绑定可读性：一组探针

对象：
- P2：数字位置的变量字母，基线 1/52；
- P1：读出位置上"查询的是哪条语句"，基线 1/2；
- P3：读出位置上的答案，条件基线 1/2。

每个记录点上运行以下探针，判定规则（c_hi、c₀、"检测到 / 未检测到 / 不确定"）都与 Gate D 修订 6 相同：

| 探针 | 设置 | 与 Gate D 的不同 |
|---|---|---|
| 线性 | L-BFGS 逻辑回归，L2 1e-3（同 Gate D） | 无 |
| 线性（标准化特征） | 先按拟合集逐维减去均值、除以标准差，再用同一线性探针 | 新增。用来检查固定 L2 惩罚是否压制了方差小的方向 |
| MLP | 一层隐藏层，宽 256，超参数固定（同 Gate D） | **在每个检查点、每个记录点都运行**，不再只在线性"未检测到"时运行。这样才能比较第 0 步和之后的 MLP 可读性 |

### M3 最小对敏感度：区分"删除"和"难以读取"（新增）

**定义：**
- 对 `diag_eval` 的每个题面和每条语句 j，把语句 j 的变量字母换成题面中没有的另一个字母（由 RNG 65000 固定），其余字符全部不变，得到最小对 x′。
- 在语句 j 的 `=` 位置（4j+1）和数字位置（4j+2），对每个记录点计算：
  - δ_var = E‖h(x) − h(x′)‖ / σ，其中 σ 是 `diag_eval` 上该位置、该记录点隐藏状态的总标准差（各维方差之和的平方根）；
  - 噪声下限 ε_M3：同一输入在两种不同 batch 组成下计算两次，得到的同类量（与 Gate D 10.3 节相同）。
- 由于因果掩码，这两个位置的状态只依赖于它们之前的字符。所以 δ_var 只反映语句 j 的字母本身的影响，与查询无关。

**分类**（每个记录点、每个检查点）：

| 分类 | 条件 |
|---|---|
| 该记录点上的字母信息已被删除 | δ_var ≤ 10 ε_M3：状态在数值精度内不随字母变化 |
| 存在且线性可读 | δ_var > 10 ε_M3，且 P2 线性探针（两种中任一）为"检测到" |
| 存在，但难以线性读取 | δ_var > 10 ε_M3，线性探针都不是"检测到"，MLP 为"检测到" |
| 存在，所用探针都未读出 | δ_var > 10 ε_M3，所有探针都不是"检测到" |

另外报告 δ_var 相对第 0 步的比值，作为效应大小。

**解读边界：**
- δ_var 明显大于噪声，只说明该状态仍随字母变化：在信息论意义上，字母信息没有消失。它不说明这种信息能被模型自己的后续计算利用。
- 后续计算能否利用这种信息，要靠 E2 的受控实验回答。

### M4 注意力（Gate D D3 的 K 通用版）

- 读出位置对被查询语句的注意力占比，题组大小为 2；随机化检验用 {0, 1} 上的置换群。Gate D 修订 4、5 的门控、校准方法和判定规则都按 K=2 重做校准，校准通过后才计入。
- 描述性指标：每个检查点上，数字位置对本语句字母的注意力（各头最大值）。这是"绑定头"的一个粗略指标，用来对照 P2 的变化。

### M5 学习信号（Gate D D5 的 K 通用版）

测量项与 Gate D 8.7.4 相同：
- S/(V_b+S)、同一题面不同查询的梯度余弦；
- O、F 两种方案的实测 tr Var（K=2 时成对方式 P 就是 F）；
- d·∇J、d·∇K 及余弦、‖∇L_roots‖ 与 ‖∇L_within‖；
- 沿 u 的信噪比。

K 通用的解析关系：
- 题组内满足 Σ_q r_q = 0。
- tr Var(G_O) = (V_b + S)/B，tr Var(G_F) = K·V_b/B。
- 所以 F 方案降低噪声，当且仅当 S > (K−1)·V_b。K=4 时为 S > 3V_b，与 Gate D 一致；K=2 时为 S > V_b。

不看查询的模型在平台期的预期：
- ḡ 远小于 r，且 r 在题组内对称时，同一题面不同查询的梯度余弦接近 −1/(K−1)。K=4 时为 −1/3，Gate D 实测 −0.33；K=2 时为 −1。
- 平台期 L_within ≈ ln K。

## 5. 事件时刻与 E1 的预先约定读法

### 5.1 事件定义

对每次运行，在检查点序列上定义以下事件：
- 事件时刻 = 第一个满足条件、**并且下一个检查点也满足**的检查点。
- 第 12,000 步仍满足条件时，不要求下一个检查点。
- 到第 12,000 步都没有发生，记为"未发生"。

| 事件 | 条件（都在 `diag_eval` 上） |
|---|---|
| t_R 选根形成 | P(根数字) ≥ 0.9 |
| t_P2lin 线性可读性下降 | A_lin(t) ≤ c₀ + 0.5·(A_lin(0) − c₀) |
| t_P2mlp MLP 可读性下降 | 同上，用 MLP 准确率 |
| t_M3 字母信息被删除 | 所有数字位置记录点（不含 `emb`，它按定义不依赖字母）都被 M3 分类为"已被删除" |
| t_G 梯度形态转变 | 全部参数的同一题面梯度余弦 ≤ 0.5 × (−1/(K−1)) |
| t_Q 出现查询利用 | 查询不敏感率 < 0.9，并且 J 的分组 95% 置信区间下限 > 0 |
| t_L 在开发集上学会 | `dev_heldout` 上准确率 ≥ 90%，换查询双对率 ≥ 80% |

- A_lin(t)：数字位置各记录点中，线性探针（两种）准确率的最大值，不含 `emb`。取最大值是为了只要某处仍可读，就不判为下降。

### 5.2 时间顺序的读法

- 同一次运行中，两个事件在同一检查点发生，记为"同时"。检查点间隔就是时间分辨率的上限，结论不得超出这个分辨率。
- 跨种子：
  - 5 个种子关系相同，为"一致"；
  - 4 个相同，为"多数"；
  - 其余为"不一致"。
  - 桥接的 3 个种子只用"一致"或"不一致"。

| 观察 | 预先约定的读法 |
|---|---|
| t_P2lin 早于 t_R | 线性可读性下降发生在选根形成之前，不是平台期的后果。更可能是早期更新本身改写了数字位置的表示 |
| t_P2lin 与 t_R 同时 | 在这个分辨率下无法区分先后 |
| t_P2lin 晚于 t_R | 与"可读性下降是选根平台期的后果"一致，例如没有被使用的信息得不到维持 |
| t_Q 早于 t_R，之后 J 回落 | 存在一个早期的查询利用萌芽，后来被选根解压过 |
| t_Q 未发生，或晚于 t_R | 选根先形成。若此后 J 一直不升，与"对称平台"假设一致 |
| t_M3 未发生，而 t_P2lin 发生 | 字母信息没有被删除，只是线性可读性下降。直接回应 Gate D 审核提出的问题 |
| t_M3 发生 | 在数值精度内，该位置的字母信息被删除 |

### 5.3 是否学会（每个种子，`test_heldout`，第 12,000 步）

沿用 budget_a 的三个等级，只把随机基线换成 K=2 的值：

| 等级 | 条件 |
|---|---|
| 学会 | 准确率 ≥ 90%，换根双对率 ≥ 80%，换查询双对率 ≥ 80% |
| 出现学习迹象 | 未达到"学会"；准确率的 Wilson 95% 下限高于同一批题上最强的不看查询猜法；查询不敏感率 < 90% |
| 未满足综合学习迹象标准 | 以上都不满足 |

- 一组的结论：报告 5 个种子各自的等级和计数。5 个都相同时取该等级；否则记为"不一致"，按最低等级处理。
- 两组分别报告，不据此判断架构优劣。

## 6. 实现后、正式运行前的验证

每一项都要提交结果文件。任何一项失败都停止并报告，不放宽标准。

1. **训练脚本等价性**：`train_k.py` 与 `train_level.py` 在 K=4、种子 99 下运行 200 步，权重逐位相同。还要确认 K=2 下第 0 步保存的 checkpoint 与 `manual_seed + build` 重建的结果逐位相同。
2. **可复现性**：K=2、种子 99 运行 200 步两次，权重逐位相同。这是 2.3 节"其余 checkpoint 可重新生成"的前提。
3. **题集**：
   - 留出规则有单元测试：同一键的两种语句顺序、两个查询都被留出；
   - 3.2 节的隔离检查；
   - 独立求解器核对。
4. **诊断代码**：
   - 在一个 K=4 的非正式模型上，新代码的 M1、M2（线性、MLP）、M4、M5 与 Gate D 代码给出相同的数值（容差事先固定：逐位相同，或 ≤ 1e-6）；
   - M2 新增的标准化线性探针、M3 用合成数据和非正式模型做阳性和阴性对照：
     - 构造一个字母信息被精确删除的非正式模型（例如，让两个字母的嵌入相同），M3 应判为"已被删除"；
     - 把字母信号缩小到 1e-3 倍，M3 仍应判为"存在"；
     - 构造一个线性不可读、但非线性可读的合成表示（例如 XOR 型编码），线性探针应为"未检测到"，MLP 应为"检测到"。
5. **D3 型检验在 K=2 下的校准**：按 Gate D 修订 4、5 的方案，把 K 改为 2 后重做。校准参数要在运行前另行固定并提交。
6. **启动脚本**：沿用 Gate D 的约定（退出码、结果文件检查、故障注入测试）。
7. **计时**：在非正式种子 99 上测训练和诊断的时间，确定工作量后冻结。
   - 预算：训练约 1.5 小时（4 个并行；按 budget_a 的实测和序列长度估计，实测后修正），诊断不超过 6 小时。
   - 工作量等级只允许减少 M5 的 batch 数 R，以及线性"检测到"时 P1、P3 上的 MLP。不允许减少检查点、题集规模，或 P2 上的任何探针。
   - 最低等级仍超出预算时，停止并报告，不自行削减其他部分。
