## 0. 研究问题与范围

**主问题**（按 Gate D 最终审核确定）：为什么训练让变量信息变得难以读取，同时模型迅速收敛到不依赖查询的"在根数字里选一个"策略？

Gate D 给出的出发点：
- 以下都是探索性数据，不是已证实的结论。
- 第 0 步，数字位置上的变量字母能以 53%–66% 的准确率被线性读出。
- 第 3000 步，降到 4%–26%；第 12,000 步，降到 2%–15%。
- 同期 MLP 探针仍有 9.6%–34.5%，随机水平为 1.9%。所以目前只能说"变得难以线性读取"，不能说"被删除"。
- "选根"在前 3000 步内形成，同时梯度形态发生转变：同一题面不同查询的梯度余弦从约 0 变为 −0.33。

## 1. 任务

### 1.1 两变量直接查值（K=2）

- 格式：`a=3;b=7;|b?` → `7`。
- 生成方式：由 `gen_gate_a/levels.py` 的 `_chains_prompt(rng, [1, 1])` 生成（import 使用，不修改），与 A 级相同：
  - 2 个不同的变量字母，2 个不同的根数字；
  - 语句顺序随机，查询的变量在两条语句中均匀分布。
- 位置：
  - 字母在 0、4，`=` 在 1、5，数字在 2、6；
  - 查询字母在 9，读出位置 `?` 在 10；
  - 输入长 11，答案在第 11 位。
- 模型：`build(arm, 2)`，即 `task_cfg(4, 2)`，max_seq_len = 12。
  - 参数量与 K=4 相同：OpenMythos 609,698，Transformer 607,104。
  - 已核实：同一种子下，K=2 与 K=4 的全部可训练参数初始值逐位相同。OpenMythos 只有 RoPE 预计算缓冲区（`freqs_cis`、`freqs_cis_mla`）因长度不同而不同；实现时核对两者的前 12 行逐位相同。
  - 所以同一种子下，K=2 和 K=4 的运行从同一个初始化出发，可以按种子配对比较。
- 随机水平：在根数字里随机猜为 50%。
- 不看查询的猜法：在同一批题上计算以下几种，取其中最强的作为基线：随机猜、第一条语句的数字、最后一条语句的数字、较大的根、较小的根。
- 模型自身的"数字偏好"规则只作描述，沿用 Gate D D1 的定义（`d1.digit_preference`：在拟合集上估计 P(预测 = d | d 是根)，选偏好最高的根）。它是从模型预测中估计的，不作为不看查询的基线。

### 1.2 为什么需要留出题面

K=2 的题目空间很小：
- 有序字母对 52×51，有序数字对 10×9，共 238,680 个题面，477,360 道题。
- 12,000 步 × 64 题 = 768,000 次抽样，约 80% 的题会在训练中出现。
- 如果不留出，开发集、测试集上的准确率无法区分"学会规则"和"记住了题"。

**留出方式**：
- 以题面中两条语句构成的无序集合，例如 {(a,3), (b,7)}，作为键。
- 键的 sha256 对 10 取余为 0 的题面留出，约占 10%。两种语句顺序和两个查询都一起留出。
- 训练时遇到留出题面就重新抽样。
- 开发集、测试集、诊断集都只从留出题面中抽取，所以训练中**不可能**见过这些题。
- D5 型梯度测量（M5）估计的是训练分布下的梯度，所以它的题池从非留出题面中抽取。

### M2 绑定可读性：一组探针

对象：
- P2：数字位置的变量字母，基线 1/52；
- P1：读出位置上"查询的是哪条语句"，基线 1/2；
- P3：读出位置上的答案，条件基线 1/2。

每个记录点上运行以下探针，判定规则（c_hi、c₀、"检测到 / 未检测到 / 不确定"）都与 Gate D 修订 6 相同：

| 探针 | 设置 | 与 Gate D 的不同 |
|---|---|---|
| 线性 | L-BFGS 逻辑回归，L2 1e-3（同 Gate D） | 无 |
| 线性（标准化特征） | 先按拟合集逐维减去均值、除以标准差，再用同一线性探针 | 新增。用来检查固定 L2 惩罚是否压制了方差小的方向 |
| MLP | 一层隐藏层，宽 256，超参数固定（同 Gate D） | **在每个检查点、每个记录点都运行**，不再只在线性"未检测到"时运行。这样才能比较第 0 步和之后的 MLP 可读性 |

- 植入信号灵敏度。

### M3 最小对敏感度：区分"删除"和"难以读取"（新增）

**定义：**
- 对 `diag_eval` 的每个题面和每条语句 j，把语句 j 的变量字母换成题面中没有的另一个字母（由 RNG 65000 固定），其余字符全部不变，得到最小对 x′。
- 在语句 j 的 `=` 位置（4j+1）和数字位置（4j+2），对每个记录点计算：
  - δ_var = E‖h(x) − h(x′)‖ / σ，其中 σ 是 `diag_eval` 上该位置、该记录点隐藏状态的总标准差（各维方差之和的平方根）；
  - 噪声下限 ε_M3：同一输入在两种不同 batch 组成下计算两次，得到的同类量（与 Gate D 10.3 节相同）。
- 由于因果掩码，这两个位置的状态只依赖于它们之前的字符。所以 δ_var 只反映语句 j 的字母本身的影响，与查询无关。

**分类**（每个记录点、每个检查点）：

| 分类 | 条件 |
|---|---|
| 该记录点上的字母信息已被删除 | δ_var ≤ 10 ε_M3：状态在数值精度内不随字母变化 |
| 存在且线性可读 | δ_var > 10 ε_M3，且 P2 线性探针（两种中任一）为"检测到" |
| 存在，但难以线性读取 | δ_var > 10 ε_M3，线性探针都不是"检测到"，MLP 为"检测到" |
| 存在，所用探针都未读出 | δ_var > 10 ε_M3，所有探针都不是"检测到" |

另外报告 δ_var 相对第 0 步的比值，作为效应大小。

**解读边界：**
- δ_var 明显大于噪声，只说明该状态仍随字母变化：在信息论意义上，字母信息没有消失。它不说明这种信息能被模型自己的后续计算利用。
- 后续计算能否利用这种信息，要靠 E2 的受控实验回答。

### M4 注意力（Gate D D3 的 K 通用版）

- 读出位置对被查询语句的注意力占比，题组大小为 2；随机化检验用 {0, 1} 上的置换群。Gate D 修订 4、5 的门控、校准方法和判定规则都按 K=2 重做校准，校准通过后才计入。
- 描述性指标：每个检查点上，数字位置对本语句字母的注意力（各头最大值）。这是"绑定头"的一个粗略指标，用来对照 P2 的变化。

### M5 学习信号（Gate D D5 的 K 通用版）

测量项与 Gate D 8.7.4 相同：
- S/(V_b+S)、同一题面不同查询的梯度余弦；
- O、F 两种方案的实测 tr Var（K=2 时成对方式 P 就是 F）；
- d·∇J、d·∇K 及余弦、‖∇L_roots‖ 与 ‖∇L_within‖；
- 沿 u 的信噪比。

K 通用的解析关系：
- 题组内满足 Σ_q r_q = 0。
- tr Var(G_O) = (V_b + S)/B，tr Var(G_F) = K·V_b/B。
- 所以 F 方案降低噪声，当且仅当 S > (K−1)·V_b。K=4 时为 S > 3V_b，与 Gate D 一致；K=2 时为 S > V_b。

不看查询的模型在平台期的预期：
- ḡ 远小于 r，且 r 在题组内对称时，同一题面不同查询的梯度余弦接近 −1/(K−1)。K=4 时为 −1/3，Gate D 实测 −0.33；K=2 时为 −1。
- 平台期 L_within ≈ ln K。

## 5. 事件时刻与 E1 的预先约定读法

### 5.1 事件定义

对每次运行，在检查点序列上定义以下事件：
- 事件时刻 = 第一个满足条件、**并且下一个检查点也满足**的检查点。
- 第 12,000 步仍满足条件时，不要求下一个检查点。
- 到第 12,000 步都没有发生，记为"未发生"。

| 事件 | 条件（都在 `diag_eval` 上） |
|---|---|
| t_R 选根形成 | P(根数字) ≥ 0.9 |
| t_P2lin 线性可读性下降 | A_lin(t) ≤ c₀ + 0.5·(A_lin(0) − c₀) |
| t_P2mlp MLP 可读性下降 | 同上，用 MLP 准确率 |
| t_M3 字母信息被删除 | 所有数字位置记录点（不含 `emb`，它按定义不依赖字母）都被 M3 分类为"已被删除" |
| t_G 梯度形态转变 | 全部参数的同一题面梯度余弦 ≤ 0.5 × (−1/(K−1)) |
| t_Q 出现查询利用 | 查询不敏感率 < 0.9，并且 J 的分组 95% 置信区间下限 > 0 |
| t_L 在开发集上学会 | `dev_heldout` 上准确率 ≥ 90%，换查询双对率 ≥ 80% |

- A_lin(t)：数字位置各记录点中，线性探针（两种）准确率的最大值，不含 `emb`。取最大值是为了只要某处仍可读，就不判为下降。

### 5.2 时间顺序的读法

- 同一次运行中，两个事件在同一检查点发生，记为"同时"。检查点间隔就是时间分辨率的上限，结论不得超出这个分辨率。
- 跨种子：
  - 5 个种子关系相同，为"一致"；
  - 4 个相同，为"多数"；
  - 其余为"不一致"。
  - 桥接的 3 个种子只用"一致"或"不一致"。

| 观察 | 预先约定的读法 |
|---|---|
| t_P2lin 早于 t_R | 线性可读性下降发生在选根形成之前，不是平台期的后果。更可能是早期更新本身改写了数字位置的表示 |
| t_P2lin 与 t_R 同时 | 在这个分辨率下无法区分先后 |
| t_P2lin 晚于 t_R | 与"可读性下降是选根平台期的后果"一致，例如没有被使用的信息得不到维持 |
| t_Q 早于 t_R，之后 J 回落 | 存在一个早期的查询利用萌芽，后来被选根解压过 |
| t_Q 未发生，或晚于 t_R | 选根先形成。若此后 J 一直不升，与"对称平台"假设一致 |
| t_M3 未发生，而 t_P2lin 发生 | 字母信息没有被删除，只是线性可读性下降。直接回应 Gate D 审核提出的问题 |
| t_M3 发生 | 在数值精度内，该位置的字母信息被删除 |

### 5.3 是否学会（每个种子，`test_heldout`，第 12,000 步）

沿用 budget_a 的三个等级，只把随机基线换成 K=2 的值：

| 等级 | 条件 |
|---|---|
| 学会 | 准确率 ≥ 90%，换根双对率 ≥ 80%，换查询双对率 ≥ 80% |
| 出现学习迹象 | 未达到"学会"；准确率的 Wilson 95% 下限高于同一批题上最强的不看查询猜法；查询不敏感率 < 90% |
| 未满足综合学习迹象标准 | 以上都不满足 |

- 一组的结论：报告 5 个种子各自的等级和计数。5 个都相同时取该等级；否则记为"不一致"，按最低等级处理。
- 两组分别报告，不据此判断架构优劣。

### 9.2 M2：标准化与非标准化线性探针的对照（取代第 4 节 M2 表中"线性（标准化特征）"一行）

**更正**：Gate D 的 `d2.fit_linear()` 已经先按拟合集逐维减均值、除以标准差，再做带 L2 的逻辑回归。初稿所称的"新增标准化特征线性探针"，与 Gate D 的线性探针是同一种方法，并非新方法。

修订后的探针组：

| 探针 | 特征处理 | 其余设置 | 作用 |
|---|---|---|---|
| 线性·标准化 | 与 Gate D `fit_linear()` 完全相同：拟合集均值和标准差标准化 | L-BFGS 多类逻辑回归；损失为平均交叉熵 + 1e-3·‖W‖²；收敛标准为梯度最大值 ≤ 1e-6 | **连续性基准**。所有事件和比较都以它为准 |
| 线性·原始特征 | 不减均值、不除标准差 | 与上一行完全相同：同一拟合和评测数据、同一分类器、同一 λ = 1e-3（作用于 W）、同一收敛标准；报告实际收敛梯度 | 对照：说明特征尺度对线性读出的影响 |
| MLP | 与 Gate D `fit_mlp()` 完全相同（内部也做标准化） | 宽 256，固定设置 | 在每个检查点、每个记录点都运行（同初稿） |

- 两种线性探针之间的差异，主要来自特征尺度与固定 L2 惩罚的相互作用：在原始特征上，方差小的方向相当于受到更强的惩罚。它不代表网络内部的信息增加或减少，报告中也不能这样解读。
- 正式判定用语沿用 Gate D 修订 6 的规则（"检测到 / 未检测到 / 不确定"、c_hi、c₀）。对于 52 类的 P2，"检测到"要求置信区间下限 ≥ c + 0.5·(1 − c) ≈ 0.51。
- 准确率高于随机水平、但没有达到这一标准时，一律写作"高于随机水平，但未达到正式检测标准"，不得等同于"检测到"。
- 另设一个**描述性标记**"明确高于随机"：分组 95% 置信区间下限 > c₀ + 0.10，并且高于打乱标签对照的置信区间上限。它只用于描述，不参与任何正式判定，也不能取代"检测到"。

### 9.3 M3：局部输入扰动实验与判定语义（取代第 4 节 M3 的全部内容）

**性质**
- M3 是**局部输入扰动实验**。它的题面由 `diag_eval` 派生，与 `diag_eval` 逐题成对，不是独立的题集，也不是泛化测试。
- 报告中单列，不与任何独立测试的结果合并。

**构造**（RNG 65000，事先固定）
- 对 `diag_eval` 的每个题面、每条语句 j，取 3 个题面中没有的替换字母，共 1000 × 2 × 3 = 6000 个最小对。
- 采用**一致改名**：把语句 j 的变量字母换成替换字母；如果查询的正是这个变量，查询字母也一起换掉。
  - 这样 x′ 仍是一道完整、有效的题，答案不变，任务语义按构造保持。
  - 由独立求解器核对每个 x′。
- 逐对报告 x′ 是否仍属于 10% 的留出题面。留出与非留出两个子集的结果也分开描述。
- 被测位置是 4j+1（`=`）和 4j+2（数字），都在查询（位置 9）之前。由于因果掩码，被测状态与查询是否改名无关，只可能受 MoE 分批带来的数值舍入影响。这一点由下面的阴性对照核对。

**测量**（每个检查点、每个记录点、每种位置）
- 逐对变化 δ_i = ‖h(x_i) − h(x_i′)‖ / σ。σ 是 `diag_eval` 上该位置、该记录点隐藏状态的总标准差。
- 逐对噪声 ε_i：同一输入 x_i 在两种不同 batch 组成下各算一次，按同样方式取差的范数。
- 判定阈值：τ = 10 · max_i ε_i，即该记录点上的最大噪声乘以 10。
- 报告：
  - δ_i 的分布：最小值，1%、5%、25%、50%、75%、95% 分位数，最大值，以及均值；
  - 零变化比例：δ_i ≤ τ 的最小对所占比例，以及 δ_i 逐位为 0 的比例；
  - ε_i 的分布；
  - 以上全部按记录点、检查点、位置类型（`=` / 数字）和留出子集分别给出。

**对照**（每个检查点都做的硬性检查。任何一项失败都说明测量有错，立即停止并报告）
- 阴性对照：只做查询交换（仍是有效题）。查询之前的位置 0–8，所有最小对都必须满足 δ_i ≤ τ。
  - 后面字符的改变可能通过 MoE 分批舍入影响前面的位置，所以这里用同一个 10 倍噪声规则，而不是要求逐位为 0。
  - 正式运行前，要在非正式模型上确认这一对照能够通过（第 6 节）。不能通过时停止并报告，不放宽阈值。
- 阳性对照：在被替换字母本身的位置 4j、`emb` 记录点上，所有最小对都必须满足 δ_i > τ，因为词嵌入本身变了。

**正式判定用语**（每个记录点、每个检查点）

| 用语 | 条件 |
|---|---|
| **在预设最小对和数值精度下，未检测到字母敏感性** | 没有任何一个最小对满足 δ_i > τ |
| **发现字母敏感性** | 至少一个最小对满足 δ_i > τ。必须同时报告敏感比例 s（满足 δ_i > τ 的比例，附题面分组置信区间）和 δ_i 的分布 |

**解读边界**
- "未检测到字母敏感性"只适用于所测的最小对、位置、记录点和数值精度。它不等于"信息被删除"：其他替换字母、其他位置，或低于数值精度的变化，都没有被排除。
- "发现字母敏感性"只说明这些最小对上，状态会随字母变化。它不证明 52 类字母的信息都可以恢复，也不说明模型能利用这些信息。
- 报告中不使用"信息完整保留"或"信息被删除"这类表述。

**与 M2 合读时允许的表述**（取代初稿 M3 的分类表）

| M3 | M2（P2，同一记录点） | 允许的表述 |
|---|---|---|
| 发现字母敏感性（比例 s） | 某种探针正式"检测到" | 状态随字母变化，且该探针能以达到正式标准的准确率读出变量字母 |
| 发现字母敏感性（比例 s） | 没有探针"检测到" | 状态随字母变化，但所用探针都没有达到正式检测标准，信息能否恢复不确定。若有"明确高于随机"标记，可以另行描述 |
| 未检测到字母敏感性 | 任意 | 在预设最小对和数值精度下未检测到字母敏感性。此时探针若高于随机，要检查是否来自其他位置的信息（例如相邻字符），并如实报告 |

### 9.4 事件与读法的相应修改（取代 5.1 中 t_P2lin、t_M3 两行，以及 5.2 中涉及 M3 的两行）

### 9.5 正式判定的基线固定为 50%（取代 1.1 中"不看查询的猜法"一条，以及 5.3 中"出现学习迹象"的条件）

- 依据：每个题面的两个根数字不同，并且两个查询都参与评测。任何完全不看查询的确定性策略，在每个题面上都恰好答对 1 题，准确率恰好是 50%。不看查询的随机策略，期望准确率也是 50%。
- 所以正式基线直接固定为 50%，不在测试集上挑选"最强不看查询基线"，以免在测试集上选择比较对象带来统计解释问题。
- 修订后的"出现学习迹象"：
  - 未达到"学会"；
  - 准确率的题面分组 95% 置信区间下限 > 50%。用分组自助法，设置与 Gate D 的 `common.grouped_bootstrap` 相同：2000 次，seed 0，按题面整组重抽；
  - 查询不敏感率 < 90%。
- "学会"的门槛不变：准确率 ≥ 90%，换根双对率 ≥ 80%，换查询双对率 ≥ 80%。
- 第一条或最后一条语句、较大或较小的根、模型自身的数字偏好等策略，只作描述性分析，不作为比较基线。

## 10. 修订 2（按 7a0d89e 的审核意见；只固定两处局部边界）

### 10.1 M3 的零方差处理（补充 9.3 节"测量"和"对照"，以及 9.10 节）

- 在某些记录点和位置上，`diag_eval` 的所有题目都是同一个状态。例如 `emb` 记录点上的 `=` 位置，所有题目都是同一个 `=` 的嵌入。这时样本标准差 σ 恰好为 0。这是测量位置本身没有变化，不是模型故障。
- σ 按检查点、记录点、位置分别计算。规则如下：

| 情况 | 处理 |
|---|---|
| σ > 0 | 按 9.3 节的原公式计算 δ_i、ε_i 和 τ，阈值不变 |
| σ = 0 | 不做除法。记为"标准化敏感度不可计算（σ = 0）"，并单独记录原因。同时报告原始状态差 ‖h(x_i) − h(x_i′)‖ 的分布和原始噪声 ε_i 的分布。**不得判为"未检测到字母敏感性"，也不得判为"信息被删除"** |

- 9.4 节的事件 t_M3 只统计 σ > 0 的数字位置记录点（不含 `emb`）。若某个数字位置记录点出现 σ = 0，单独报告，并在事件表中注明已排除。
- 阴性对照和阳性对照，都只在 σ > 0 的（记录点，位置）组合上执行。σ = 0 的组合只报告原始差值。
- 9.10 节的合成验证（植入信号、局部变化等）都在 σ > 0 的记录点上进行。
- 9.10 节增加一项回归测试：构造一个 σ = 0 的记录点（例如 `emb` 上的 `=` 位置）。要求：
  - 不做除法，输出中没有 NaN 或无穷大；
  - 判为"不可计算"，而不是"未检测到"；
  - 不进入 t_M3 的统计。

### 10.2 50% 基线的理论说明（取代 9.5 节"依据"一条；门槛和比较方式不变）

- 每个题组都包含两个查询，两道题的答案是两个不同的根数字。在这样的完整题组上：
  - 任何与查询无关的确定性预测，最多答对一道；
  - 只有预测恰好是两个根数字之一时，才恰好答对一道。例如题面 `a=3;b=7`，总是回答 9 的模型两道都错。
- 与查询无关的随机预测：设预测分布为 p，它不随查询变化，则每个题组的期望答对数为 p(d_a) + p(d_b) ≤ 1，即期望准确率不超过 50%。
- 所以 50% 是查询无关策略准确率的**上界**，作为正式比较基准。它不是所有查询无关预测器都必然达到的准确率。
- 9.5 节修订后的"出现学习迹象"条件和"学会"门槛都不变。
