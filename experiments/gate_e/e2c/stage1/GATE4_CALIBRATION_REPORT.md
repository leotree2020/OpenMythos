## 5. C2 的六次短程训练与 λ₂

做法：
- 在种子 91–93 上，用 λ₂ = λ（OpenMythos 0.1，Transformer 1.0）训练 C2 各 300 次更新，共 6 个运行，全部完成，退出码 0。
- 能量定义：E_W = Σ_{u=1}^{300} r_u²。r_u 是 λ·L_aux 对全部被监督状态的直接误差信号的 Frobenius 范数，在裁剪之前计算。
- E_W^C1 取 C1 校准运行在选中 λ 下的前 300 次更新。

| 组 | 种子 | E_W^C1(λ) | E_W^C2(λ) |
|---|---|---|---|
| OpenMythos（λ = 0.1） | 91 | 9.7718e-4 | 4.7123e-4 |
| | 92 | 9.2307e-4 | 4.6028e-4 |
| | 93 | 1.12440e-3 | 5.8791e-4 |
| | **平均** | **1.00822e-3** | **5.06472e-4** |
| Transformer（λ = 1.0） | 91 | 0.096787 | 0.048929 |
| | 92 | 0.095146 | 0.049273 |
| | 93 | 0.096030 | 0.048200 |
| | **平均** | **0.095988** | **0.048800** |

计算：λ₂ = λ · √(平均 E_W^C1 / 平均 E_W^C2(λ))，再限制在 [λ/10, 10λ] 内。

| 组 | 计算 | λ₂ | 允许范围 | 触及边界 |
|---|---|---|---|---|
| OpenMythos | 0.1 × √(1.00822e-3 / 5.06472e-4) = 0.1 × √1.99066 | **0.141091** | [0.01, 1.0] | 否 |
| Transformer | 1.0 × √(0.095988 / 0.048800) = √1.96696 | **1.402479** | [0.1, 10] | 否 |

- 分母都大于 0 且是有限值，F4 不适用。
- 只计算一次，没有迭代。
- 关于"按种子取平均"：预注册写的是"E_W^C1 按种子取平均"，公式中只有一个 E_W^C2(λ)，而它也是在同样 3 个种子上测得的。实现中两者都取 3 个种子的平均（比值是两个平均数之比）。这一读法写在 `s1_gate4.py` 的文档字符串和代码中，校准运行之前就已提交（5ef6a54），运行后没有改动。如审核认为应当另作解释，请指出，我不会自行重算。
