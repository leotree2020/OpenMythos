## 0. 背景、范围与原则

### 0.1 E1 给出的出发点（探索性观察，不是已证实的结论）

E1（`experiments/gate_e/E1_REPORT.md`）的 K=2 两变量查值任务中：

1. **线性可读性下降早于选根形成**：10 次运行中，数字位置变量字母的线性可读性（P2，线性·标准化探针）持续下降（t_P2lin），都在第 50 或 75 步，早于选根形成 t_R（第 150 步）。两组都是 5/5 一致。
2. **字母敏感性仍在**：所有运行中 t_M3 都未发生，数字位置的状态仍随字母变化（s = 1.000）。K=2 的 MLP 可读性也没有持续下降（t_P2mlp 未发生，10/10）。
3. **选根之后的分化**：所有 K=2 运行都先进入选根阶段，之后出现分化：
   - Transformer 5/5 学会；
   - OpenMythos 2/5 学会，另外 3 个停在与查询无关的选根策略上（test_heldout 准确率约 0.50，查询不敏感率 0.985–1.000）。
4. **第 12000 步的可读性**（描述）：学会的 7 次运行，A_lin 都高于 t_P2lin 门槛；未学会的 3 次都低于门槛。

E1 审核结论：
- 时间先后不能证明可读性下降导致了失败；
- "简单探针读不出来"不等于"信息被删除"；
- 需要研究的是：为什么部分训练轨迹能离开选根阶段，另一些却停在那里。

### 0.2 本实验要回答的问题

在训练中加入一个辅助任务，让数字位置的字母信息保持线性可读，是否足以让模型更可能、更早地离开选根平台，学会按查询取值？

- E2-c 检验的是**充分性**型干预："保持可读"是否改善学习。
- 它不检验必要性："失去可读性是否必然导致失败"不在本实验范围内。

### 0.3 原则

- **先复现再改进**：
  - 任何干预条件运行之前，先在当前环境中逐位复现 E1 的训练轨迹和诊断数值（第 6 节 R1–R3）；
  - 复现不通过，就停止，不进入干预。
- **上游优先**：
  - 训练数据流、初始化、优化器、学习率计划、batch、步数、留出规则都与 E1 完全相同；
  - 只增加辅助损失，不修改模型架构，不修改 `open_mythos/` 和任何已归档代码。
  - E2-c 的新代码只放在 `experiments/gate_e/e2c/`，以只读方式导入 E1 模块。
- **每阶段结束后停止**：每个阶段结束后停止并等待审核，不自动推进（第 10 节）。
- **不比较架构**：两组分别报告，不据此判断架构优劣。

## 1. 假设、因果机制与可证伪条件

### 1.1 假设的因果链

要按查询取值，读出位置（`?`，位置 10）必须找到"变量字母与查询字母相同"的那条语句，再取出它的数字。一种可能的实现方式是：

1. **绑定**：数字位置（2、6）的状态中，含有可被线性读取的"本语句的变量字母"；
2. **匹配**：读出位置的注意力用查询字母与这些"字母键"做匹配，从而选中正确的数字；
3. **逃离平台**：匹配一旦形成，梯度就开始支持按查询取值，模型离开"在两个根数字里选一个"的平台。

**假设 H**：训练早期，数字位置字母信息的线性可读性下降，使第 2 步缺少可用的"键"，于是选根平台更难离开。所以，人为保持这种线性可读性，应提高学会的比例或加快学会。

**竞争解释**（本设计需要能区分或如实标出）：
- **A1 伴随现象**：可读性下降只是伴随现象。学会与否取决于别的因素，例如梯度对称性的打破（t_G），或注意力路径的形成。那么保持可读性不会改善学习。
- **A2 一般辅助监督效应**：在数字位置上做任何可学习的辅助监督，都可能通过额外梯度、正则化、防止表示塌缩，或改变优化器状态而影响学习，与字母内容无关。这由 C2 检验（第 3 节）。
- **A3 反方向**：E1 中学会的运行最后 A_lin 回到门槛以上，可能是"学会了才需要可读"，即学会导致可读，而不是可读导致学会。保持可读如果无效，与 A3 一致，但不能证明 A3。

### 1.2 两类结果必须分开

| 类别 | 问题 | 指标 | 作用 |
|---|---|---|---|
| **操纵检验 H-M**：保持线性可读性 | 干预是否真的让数字位置的字母保持线性可读？ | 独立探针的 A_lin(t)，以及 t_P2lin 是否发生（5.2） | 前提条件。操纵失败时，不能检验 H |
| **结果检验 H-Y**：提高任务学习 | 保持可读之后，是否更可能、更早学会按查询取值？ | 新封存测试集上第 12000 步是否"学会"；开发集上的 t_L（5.1） | 主要结论 |

- 操纵成功本身不是"实验成功"。
- 学习改善如果没有伴随操纵成功，也不能归因于"保持可读"。

### 1.3 可证伪条件（以 OpenMythos 的确认性检验为准，完整判定见 7.1）

- **支持 H，并且是绑定特异的**：
  - 操纵检验通过；
  - C1 的学会率显著高于 C0，并且显著高于 C2；
  - 辅助强度平衡检查通过（3.5）。
- **与 H 的强效应版本不相容**：
  - 操纵检验通过；
  - C1 对 C0 不显著；
  - 学会率配对差的单侧 99% 上界低于最小关注效应 Δ_min = 0.30。
  - 准确措辞见 7.1。这不否定"小于 0.30 的效应"，也不证明没有效应。
- **其余组合**：包括只支持一般辅助效应、与 H 相反、不确定、不可判定，按 7.1 的完整判定表处理。

## 2. 任务、模型与训练配方（与 E1 完全相同）

- **任务**：K=2 直接查值，格式 `a=3;b=7;|b?` → `7`。由 `gen_gate_a/levels.py` 的 `_chains_prompt(rng, [1, 1])` 生成。字母在位置 0、4，数字在 2、6，查询字母在 9，读出位置在 10。
- **留出规则**：与 E1 相同。题面的无序语句集合作为键（`e_common.body_key`），sha256 对 10 取余为 0 的题面不进入训练。
  - 训练分布因此与 E1 完全相同，这是逐位复现 E1 的前提。
  - 代价是：可用的未见题面只有这个规则下的留出键（7.4）。
- **模型**：`build(arm, 2)`，不修改。
  - 两组：OpenMythos（T=4，ACT 读出，原生代码）和参数量匹配的 Transformer。
- **训练**：
  - AdamW，学习率 2e-3，按 `budget_a/schedule.extended_lr`（预热 100 步，余弦到第 3000 步，之后保持 2e-4）；
  - 权重衰减 0.1，batch 64，12000 步；
  - 任务损失只在答案位置计算；
  - 梯度裁剪 1.0，范数只对模型参数计算（与 E1 相同）。
- **初始化**：`torch.manual_seed(seed); build(arm, 2)`。
- **训练数据 RNG**：`random.Random(60000 + seed)`。同一种子下，两组、三个条件的题目序列逐题相同。

## 3. 三种条件与辅助监督

### 3.1 条件

| 条件 | 训练损失 | 数字位置上的辅助标签 |
|---|---|---|
| **C0 原始训练** | L = L_task，与 E1 完全相同 | 无 |
| **C1 绑定辅助监督** | L = L_task + λ · L_aux | 本语句的变量字母（52 类） |
| **C2 非绑定辅助监督：数字编码** | L = L_task + λ₂ · L_aux | c(本语句的数字)。c 是从 10 个数字到 52 个类中 10 个类的固定单射，每个种子由 `random.Random(80000 + seed)` 抽取一次 |

- 两种辅助标签都由输入本身决定，不含查询或答案信息。
- 在因果掩码下，两种标签都只依赖数字位置之前（含该位置）的字符。

### 3.2 为什么这样设计 C2

**第一版的问题**：
- C2 用的是与输入无关的随机标签，学不会；C1 的绑定任务学得会。
- 两者的差异可能只是"可学习、梯度有结构"与"不可学习、梯度是噪声"的差异，会被误判为绑定特异性。

**在这个格式里，不存在与 C1 难度相同、又不含绑定信息的目标**（证明）：
1. 数字位置 2（第一条语句的数字）能看到的只有位置 0 的字母 L₁、位置 1 的 `=`（常量）和位置 2 的数字 d₁。
2. 任何需要从更早位置取信息的目标，都必须依赖 L₁，也就是携带本语句字母的信息，这正是绑定。
3. 不依赖 L₁ 的目标，只能是 d₁ 和位置的函数，而这些信息就在该位置的输入里。
4. 位置 6 还能看到 L₁、d₁ 和 L₂：
   - 不依赖 L₂ 的目标，要么是另一条语句的字母 L₁（错误绑定），要么是另一个根数字 d₁（与选根直接相关）；
   - 要么只依赖位置本身。
5. 结论：在相同的被监督状态上，可学习的非绑定目标只能是数字（或位置）的函数，而且必然比 C1 容易。

**所以 C2 选择数字编码**。它与 C1 只在下列两点上不同：
- 内容：数字，而不是字母；
- 难度：信息就在本位置，不需要注意力取回。

其余的监督位置、记录点、辅助头、损失形式和标签数都相同（3.4）。这个残余差异无法在相同状态上消除，在解释中必须标出（12.3）。

**不作为主对照、但可以加做的对照**（待审核决定 D1）：
- **C3-N 随机标签**：用来检验持续不衰减的辅助梯度本身的作用；
- **C2-L 字母在字母位置**：标签内容与 C1 相同，但只监督字母所在位置，用来检验"字母信息必须放在数字位置"这一点。

### 3.3 辅助头、监督位置与 ACT

**辅助头**：
- 每个监督记录点各有一个线性映射 d_model → 52；
- 用独立的 `torch.Generator().manual_seed(90000 + seed)` 初始化，之后固定，不训练；
- C1 与 C2 在同一种子下用逐位相同的头权重，因此两者都没有额外的可训练参数；
- 头是随机的，所以训练开始时两种辅助损失都约为 ln 52，两个任务都需要通过改变表示来学会。

**监督位置**：数字位置 2 和 6。

**监督记录点**（主方案）：只选在 ACT 下**总是有效**的记录点。
- OpenMythos：`e`、`h1`、`h_out`、`coda_out`；
- Transformer：`out0`、`out1`、`out2`。
- 选择理由：
  - OpenMythos 的循环里，每一轮都计算所有位置的新状态；
  - 一个位置停止累计（halted）之后，它的状态权重为 0，但仍作为注意力的键和值，影响同一题里还在运行的位置；
  - 训练中，只有当整个 batch 的所有位置都停止时，后面的循环才会被跳过。
  - 所以 `h2`–`h4` 是否被执行、是否有效，取决于各条件自身的 ACT 动态。
  - 而 `e`（循环之前）、`h1`（第 1 轮之前不可能有位置停止）、`h_out`（ACT 加权和，总是存在）、`coda_out` 在每一步、每个样本上都存在且有效。

**有效性掩码**（主方案）：所有被监督的条目都有效，掩码恒为 1。三个条件每一步的被监督条目数完全相同：64 × 2 × 记录点数（OpenMythos 4 个，Transformer 3 个）。

**损失归一化**：
- 每个记录点 r：L_r = 1/(64·2) · Σ_b Σ_{p∈{2,6}} CE(W_r · h_{b,p}^{(r)}, y_{b,p})；
- 总辅助损失：L_aux = (1/R) Σ_r L_r，每个记录点权重相同，R 为记录点数。

**对三个条件公平性的影响**：
- 被监督条目的数量和位置在 C1、C2 之间逐步相同，与 ACT 动态无关。
- 但 ACT 动态本身可能因条件而不同，这属于处理效应的一部分。例如 `h_out` 的组成会随停止时刻改变。
- 因此三个条件都记录训练 batch 上的 ACT 统计：每步执行的循环数、各轮停止的位置比例。前 1000 步每 10 步记录一次，之后每 100 步一次。在 D2c 检查点上还报告 M6。
- C0 没有辅助监督，它与 C1、C2 的 ACT 差异照常报告。

**备选方案**（待审核决定 D3）：同时监督 `h2`–`h4`。
- 掩码：样本 b 的 `h_k`（k = 2…4）有效，当且仅当在该次前向中，第 k−1 轮被执行，并且样本 b 的所有位置在第 k−1 轮之前没有全部停止。这与 E1 D2-E 的单样本 `valid` 语义一致：每个样本的停止判定彼此独立，batch 只影响是否提前退出。
- 归一化：每个记录点只在有效条目上取平均；某一步没有有效条目的记录点，不计入记录点平均。
- 公平性影响：被监督条目数会随各条件的 ACT 动态而变。因此要记录每步各记录点的有效比例，并采用以下降级规则：
  - 若在早期窗口 W 内，C1 与 C2 的平均有效比例之差 > 0.20 的种子超过 25%，就把 C1 对 C2 的比较降级为描述性。
  - 实现阶段需加做 V6：在训练 batch 上计算的掩码，与单样本掩码的一致率要 ≥ 99.9%。

**评测**：辅助头只在训练中使用，所有诊断和正式判定都不使用它。

### 3.4 梯度与监督量：能控制什么，不能控制什么

| 量 | 控制方式 | 是否控制 |
|---|---|---|
| 训练步数、更新次数、batch、学习率计划、优化器、权重衰减、裁剪规则 | 三个条件相同 | **精确控制** |
| 训练题目序列、初始化 | 同一种子下逐题、逐位相同，并逐步核对哈希（3.5） | **精确控制** |
| 被监督的状态：位置、记录点 | C1、C2 相同 | **精确控制** |
| 每步的被监督条目数 | C1、C2 相同（主方案掩码恒为 1） | **精确控制** |
| 辅助头（参数量、权重） | 固定不训练，C1、C2 同种子逐位相同 | **精确控制** |
| 损失形式、类别数 | 都是交叉熵，都是 52 类的头 | **精确控制** |
| 早期窗口 W（第 0–300 步）内的辅助误差信号能量 | 用 λ₂ 一次性校准，正式运行逐种子核对平衡（3.5） | **近似控制**，有降级规则 |
| W 之后每一步的辅助梯度大小 | 不配对。C2 可能更早学会，梯度更早衰减 | **不控制**，只记录（W 之后分窗口报告） |
| 梯度方向和结构 | 由辅助任务的内容决定 | **不控制**：这正是 C1 与 C2 要比较的差异，但其中混有难度差异 |
| 辅助任务的难度和学会时刻 | C2 的信息就在本位置，比 C1 容易 | **不控制**（3.2 已证明在相同状态上无法控制） |
| 标签熵（单个数字位置的边际分布） | C1 约为 log 52（字母近似均匀），C2 为 log 10（数字均匀） | **不控制**，只记录 |
| 参数层面的辅助梯度范数，以及它对 AdamW 一、二阶矩的影响 | 定期测量 | **不控制**，只记录 |
| 裁剪生效的比例 | 每步记录 | **不控制**，只记录；W 内的差异纳入平衡检查（3.5） |
| 辅助内容对表示的副作用 | 用 M1、M3、M6 描述 | **不控制** |

例如，数字编码可能加强数字身份的表示，从而反而巩固选根策略。这种副作用也属于 C2 对 C0 差异的一部分。

### 3.5 权重、平衡核对、零分母、裁剪与配对误差

**C1 的 λ**（实现阶段，只用非正式种子，只看可读性）：
- 候选值：λ ∈ {0.03, 0.1, 0.3, 1.0}；
- 校准种子：91、92、93，每组单独选择；
- 校准过程：C1 训练到第 3000 步，检查点为 0、25、50、75、100、150、200、300、500、1000、2000、3000，用 E1 的 `diag_fit` / `diag_eval` 计算独立探针的 A_lin(t)；
- 规则：选最小的 λ，使 3 个校准种子在第 50–3000 步的每个检查点上都满足 A_lin(t) > 门槛（门槛定义见 5.2）；
- 只看可读性：选择不看任何任务学习指标。校准运行的学习指标照常记录并在审计日志中报告；
- 都不满足时：停止并报告（F4），不扩展候选范围。

**C2 的 λ₂**（一次性校准，不迭代）：
- 定义：
  - r_t 是第 t 步辅助损失（含权重）对全部被监督状态的直接误差信号的 Frobenius 范数，在裁剪之前计算；
  - 窗口 W = 第 0–300 步，覆盖 E1 的 t_P2lin（50–75）和 t_R（150）；
  - 窗口能量 E = Σ_{t∈W} r_t²。
- 过程：
  1. 在同样的 3 个校准种子上，C2 先用 λ₂ = λ 训练到第 300 步，得到 E_C2(λ)；
  2. 取 E_C1 为 C1 校准运行在 W 内的能量，按种子取平均；
  3. λ₂ = λ · √(E_C1 / E_C2(λ))，限制在 [λ/10, 10λ] 之内。达到边界时如实报告。
- λ 和 λ₂（每组）写入冻结文件，之后不再改变。

**正式运行的平衡检查（BAL）**：

| 条件 | 要求 |
|---|---|
| 能量平衡 | 每个种子计算 B = E_C2 / E_C1（W 内，裁剪之前）。B 在 [0.5, 2] 之外的种子不超过 25% |
| 裁剪平衡 | W 内裁剪生效的步数比例，C1 与 C2 之差超过 0.20 的种子不超过 25% |

- 两条都满足才算平衡检查通过。
- 不通过时，判定表中依赖 C1 对 C2 比较（P2）的结论一律降级为描述性（7.1）。
- 第 300–3000 步和第 3000–12000 步的能量比、裁剪比例分窗口报告，不参与判定。

**零分母**：

| 情形 | 规则 |
|---|---|
| 正式运行中 E_C1 = 0 或不是有限值 | 实现错误：λ > 0 时，有限 logits 上的交叉熵梯度不可能为 0。完整性失败（F8），停止 |
| 校准中 E_C2(λ) = 0 或不是有限值 | 停止（F4） |
| 计算 B 时 E_C2 = 0 | B 记为 0，不在 [0.5, 2] 之内，计入平衡检查 |

主方案中没有逐步缩放，所以不存在逐步的分母。

**裁剪**：
- 辅助梯度先与任务梯度相加，再按模型参数的总范数统一裁剪到 1.0（规则同 E1）；辅助头不训练，不参与裁剪。
- 平衡检查用裁剪之前的 r_t。同时记录每步的裁剪系数，并据此报告"实际更新层面"的辅助能量（r_t² × 裁剪系数²）。

**配对误差**（同一种子的三个条件之间）：
- 每步训练 batch 的 token 张量计入链式 sha256，每 100 步记录一次；
- 第 0 步的参数哈希、辅助头权重哈希、C2 的数字编码 c 都要记录；
- 任何一项不一致都是完整性失败（F8），停止。
- 同一运行的 r_t 记录必须能逐位重算（V1）。

**参数层面的记录**：在前 1000 步每 10 步、之后每 100 步的记录点，额外反传一次辅助损失并记录 ‖∂L_aux/∂θ‖。
- 用 `autograd.grad`，不累加到参数梯度，不影响训练轨迹（R1″ 验证）；
- 训练耗时约 +2%，已计入预算。

**第一版逐步配对方案的处理**：
- 第一版规定 C2 逐步配对缩放（α_t = r_t^C1 / ‖∂L_rand/∂H‖），并设上限 α_t ≤ 10λ，同时又要求 V1 逐步相对误差 ≤ 1e-6。上限一旦生效，就必然违反 V1，两条规则矛盾。
- 改为可学习的 C2 之后，C2 学会以后梯度趋于 0，逐步配对需要无界放大；放大后的信号是"继续扩大已学会任务的间隔"，这本身就是新的混杂。
- 因此第二版取消逐步配对，改用固定权重加窗口能量平衡。原来的 V1 改为配对完整性与可重算性的检验（第 6 节）。

### 4.1 联合功效与敏感性分析

模拟设定：

## 5. 指标

### 5.1 任务学习（结果检验 H-Y）

- **主要指标（每次运行）**：在新的封存测试集 `test2_heldout`（7.4）上，第 12000 步是否"学会"。
  - 门槛与 E1 第 5.3 节相同：准确率 ≥ 90%，换根双对率 ≥ 80%，换查询双对率 ≥ 80%。
  - 换根双对率只在"有换根反事实的（题面，语句）对"上计算。按构造至少有 1000 对（7.4）。这是与 E1 唯一的定义差异：E1 每道题都有换根反事实。
- **关键次要指标**：t_L，即在开发集 `dev_heldout`（E1 的，7.4）的训练日志上，第一个满足"准确率 ≥ 90% 且换查询双对率 ≥ 80%"、并且下一个记录点也满足的步数。
  - 记录频率与 E1 相同：前 1000 步每 25 步，之后每 250 步。
  - 与 E1 不同的是，E2-c 直接用全部日志点，而不只用检查点。到第 12000 步仍未发生，记为"未发生"。
- **其他次要指标**：
  - 第 12000 步 `test2_heldout` 上的准确率、换根双对率、换查询双对率、查询不敏感率，以及按 E1 第 5.3、9.5 节的三个等级；
  - 在诊断集上计算的 t_R、t_Q、J。
- **置信区间**：
  - 单次运行的指标，用题面分组自助法：2000 次，seed 0（同 E1）；
  - 组间学会率的配对差，用 Newcombe 区间（方法 10）：95% 用于估计，98% 的上限用于"不相容"结论（4.1）。

### 5.2 操纵检验（H-M）

- **A_lin(t)**：数字位置各记录点（不含 `emb`）上，P2 线性·标准化探针准确率的最大值。
  - 定义、代码和判定规则都与 E1 相同；
  - 循环记录点 `h1`–`h4` 用 E1 的 D2-E 单样本有效性语义；
  - 探针在 `diag_fit` 上拟合、在 `diag_eval` 上评测（都是 E1 的题集，7.4），与训练用的辅助头无关。
- **门槛**：θ = c₀ + 0.5 · (A_lin(0) − c₀)，c₀ = 1/52。同一种子三个条件的初始化相同，所以 A_lin(0) 和 θ 也相同。
- **t_P2lin**：定义同 E1，在 E2-c 的检查点网格上计算。
- **操纵检验通过的条件**（两条都要满足）：
  1. C1 中，至少 80% 的种子 t_P2lin 未发生；
  2. 配对符号检验：C1 在第 50–3000 步各检查点上 A_lin 的最小值，高于 C0 的种子数显著（精确符号检验，双侧 α = 0.05）。
- **前提复现检查**（不是操纵条件）：C0 中至少 80% 的种子 t_P2lin 发生，即在新种子上复现 E1 的现象。不满足时如实报告，结论中要说明前提没有复现。
- **特异性检查（SPEC）**：C2 中 t_P2lin 发生的种子是否 ≥ 80%，即 C2 没有保持字母可读性。
  - 如果 C2 也保持了可读性，C1 对 C2 的比较就不再区分"保持可读"。这时的处理见 7.1 的修饰规则。
- **描述性的"外溢"**：在 OpenMythos 未被监督的循环记录点 `h2`–`h4` 上，单独报告 A_lin。

### 5.3 诊断（E2-c 精简版 D2c，沿用 E1 已验证的代码和定义）

- **检查点**（每次运行 14 个）：0、25、50、75、100、150、200、300、500、1000、2000、3000、6000、12000。它们都在 E1 的检查点网格之内。
- **每个检查点都做**：
  - M1：输出层面的指标，包括 P(根数字)、查询不敏感率、J、换查询双对率；
  - M2-P2：线性·标准化、线性·原始特征两种探针，包括打乱标签对照和同子集 `emb` 控制。
- **只在 0、75、150、3000、12000 这 5 个检查点做**：
  - M2-P2 的 MLP 探针；
  - M3 最小对敏感度，包括阴性、阳性对照；
  - M6 ACT 统计（只对 OpenMythos）。
- **只在 0 和 12000 做**：M0 实现检查。
- 不做 M4、M5 和 P1、P3。它们不是本实验的检验对象。
- 硬性检查（M0、M3 对照、探针对照）的规则与 E1 相同。
- **历史队列的 C0**：E1 的结果已经包含 D2c 的全部数值，因为 D2c 是 E1 M1/M2/M3 的子集，网格也是 E1 网格的子集。所以 C0 直接取 E1 的结果，不重新诊断；R3 核对数值相同。

## 7. 统计分析与判定

### 7.1 OpenMythos：确认性主检验族

**检验**：
- P1：C1 对 C0，第 12000 步"学会"的比例；
- P2：C1 对 C2，同样的比例。
- 两者都用配对精确 McNemar 检验（双侧），再用 Holm 校正（族内 α = 0.05）。
- 每个检验的结果记为：
  - **+**：校正后显著，C1 更好；
  - **0**：不显著；
  - **−**：校正后显著，C1 更差。
- 方向由不一致对的计数决定：C1 学会而对照未学会，对比对照学会而 C1 未学会。

**效应**：Δ₁₀ = p(C1) − p(C0)，Δ₁₂ = p(C1) − p(C2)。
- 报告 95% Newcombe 区间；
- "不相容"结论只看 98% 区间的上限，记作 U₁₀、U₁₂；
- 最小关注效应 Δ_min = 0.30。

**前提条件**（按顺序判定，满足即停）：

| 前提 | 不满足时 |
|---|---|
| 操纵检验（5.2）通过 | **不可判定：操纵失败，H 无法检验**。下表照常计算，只作描述 |
| C0 中未学会的种子 ≥ 5 个 | **学会率对比不提供信息（无改善空间）**。t_L 只作描述，不作"不相容"结论 |

**判定表**（前提都满足时；行为 P1，列为 P2）：

| P1 \ P2 | **+**（C1 优于 C2） | **0** | **−**（C2 优于 C1） |
|---|---|---|---|
| **+**（C1 优于 C0） | **支持 H（绑定特异）**：保持数字位置字母的线性可读，提高了学会率，且超过同强度的非绑定数字编码监督 | **支持"辅助监督提高学习"，但不能归因于字母内容**。若 U₁₂ < Δ_min，另写："在本设定、本样本量下，C1 相对 C2 的优势与'至少 0.30'不相容" | **辅助监督提高学习，但非绑定的数字编码更有效**：与 H 的特异性相反 |
| **0** | **不支持 H**：C1 不优于 C0，却优于 C2，提示 C2 可能有害（见 C2 对 C0 的描述）。若 U₁₀ < Δ_min，加写下文的不相容措辞 | 若 U₁₀ < Δ_min：**与 H 的强效应版本不相容**（措辞见下文）。否则：**不确定**，本样本量下无法区分"无效"和"中等效应" | **不支持 H**：C1 不优于 C0，而 C2 优于 C1 |
| **−**（C1 差于 C0） | **与 H 相反**：两种辅助都可能有害，绑定辅助的害处较小 | **与 H 相反**：绑定辅助监督损害了学习 | **与 H 相反**：绑定辅助有害，且比数字编码更差 |

**"不相容"的准确措辞**（用于 U < Δ_min 的格子）：

> 在本设定（K=2、本模型规模、本训练配方、所选 λ）和本样本量（N 个配对种子）下，数据与"C1 使第 12000 步学会率至少提高 0.30"不相容（Newcombe 98% 区间上限 = U < 0.30，对应单侧 99% 上界）。这不证明没有效应，也不排除小于 0.30 的效应。

报告中不使用"否定 H"或"证明无效"这类措辞。

**修饰规则**（作用于上表中依赖 P2 的结论）：
- **平衡检查 BAL 不通过（3.5）**：凡是依赖 P2 的结论（第一列、第三列，以及"+, 0"格中的特异性部分）都降级为描述性，并写明"两种辅助的早期强度或裁剪不平衡，C1 对 C2 的差异不能归因于内容"。
- **特异性检查 SPEC 不通过**（C2 也保持了字母可读性）：P2 比较的就不再是"是否保持可读"，而是"字母内容对数字内容"。第一列的结论改写为"保持可读本身不足以解释；字母内容的监督优于数字内容"。
- **前提复现检查不通过**（C0 未复现 t_P2lin）：所有结论加注"本实验的新种子没有复现 E1 的早期可读性下降"。

### 7.2 Transformer：确认性次检验族（单独成族，不影响 7.1 的结论）

- **学会率**：与 7.1 相同的 P1、P2 检验、前提和判定表。E1 中 5/5 学会，预计会触发"无改善空间"。

### 7.4 题集：确定性生成、反事实、排除与封存

**有限的留出键空间**：设计阶段按 E1 的真实规则和 E1 已归档的题集文件计数。只在内存中统计数量，没有保存任何键列表，没有抽样、排序或选择反事实，没有评测任何模型。代码和输出见附录 A。

| 量 | 数值 |
|---|---|
| K=2 键空间（无序语句集合） | 119,340 |
| 留出键 H（sha256 mod 10 = 0） | 12,006（10.06%） |
| E1 用掉的留出键 U（去重），来自 `dev_heldout`、`test_heldout` 主题面与换根反事实、`diag_fit`、`diag_eval`、`minpair` 中属于留出的 x′ | 5,093（按题集累计 6,091 次使用） |
| 剩余池 R* = H \ U：从未进入训练，也从未被任何模型评测 | 6,913 |
| R* 中，按"能在 R* 内找到换根反事实的语句数"分：0 / 1 / 2 | 2,784 / 3,364 / 765 |
| M1*：至少一条语句可在 R* 内换根的键 | 4,129 |

**E1 记录中的一个事实**（只作说明，不修改 E1 材料）：E1 的规则没有要求 `test_heldout` 的换根反事实与其他题集不重叠。实际上，2,000 个换根题面去重后是 1,895 个，其中有：

| 与哪个题集重合 | 键数 |
|---|---|
| `dev_heldout` | 87 |
| `test_heldout` 主题面 | 251 |
| `diag_fit` | 150 |
| `diag_eval` | 175 |
| `minpair` 的留出 x′ | 89 |

所以，部分 E1 判定用的反事实题面在判定之前已经在诊断和开发日志中被评测过（只用于汇总指标）。E2-c 的规则（下文）禁止这种情况。

**测量用题集：沿用 E1 的题集**（待审核决定 D9）：
- 训练日志用 `dev_heldout`；
- 探针拟合和诊断用 `diag_fit`、`diag_eval`；
- M3 用 `minpair`。
- 读取时按 E1 清单核对 sha256。
- 理由：
  1. 它们都是留出题面，从未进入训练；
  2. 它们只是测量工具，E2-c 的任何判定都不是在它们上面做的；
  3. C0 与 E1 用同一套测量，历史队列的 C0 可以直接用 E1 的结果，R3 也能逐位核对；
  4. 新建这些题集需要约 2,500 个键，会消耗 R* 的 36%，并减少可用的测试题面。
- 正式判定只用新的 `test2_heldout`。

**`test2_heldout` 的构成**：
- 1000 个题面，每个题面两个查询，共 2000 道主题；
- 换查询反事实：同一题面的另一个查询，不需要新的键；
- 换根反事实：每个题面至少 1 个，最多 2 个（见下文第 7–8 步）。
- 全部键都在 R* 中。
- 按构造，它与 E1 的任何题集、与 E2-c 用到的任何题集都不重叠；E2-c 的任何模型在判定之前都不会在其中任何题面上被评测。
- 换根反事实可以与 test2 内的其他题面相同，这种情况的数量要报告；它们一律不得来自 R* 之外。

**确定性算法**：

阶段 2（数据准备，需要单独授权）：
1. 读取 E1 的 K=2 题集文件，按 E1 清单核对 sha256，不符就停止。
2. 用 E1 的 `body_key` / `is_heldout` 规则，按规范顺序枚举键空间，得到 H：字母对按 `LETTERS` 顺序取 l₁ < l₂，数字 d₁ ≠ d₂ 按字符顺序。
3. 计算 U：E1 各题集主题面、全部换根反事实，以及 `minpair` 中属于留出部分的 x′ 的键。再求 R* = H \ U，以及 M1* = {k ∈ R*：至少一条语句 j 存在不在 k 中的数字 d′，使换根后的键 ∈ R*}。
4. 核对 |H|、|U|、|R*|、|M1*| 与附录 A 的设计阶段数值（12,006 / 5,093 / 6,913 / 4,129）完全一致；不一致就停止（V2）。
5. 把 R*、M1* 按键字符串排序，各自的规范序列化（每行一个键）的 sha256 写入冻结文件。键列表本身不保存。
6. 盐值承诺：冻结之前，审核人提供 sha256(salt)，写入冻结文件（D5）。

阶段 4（正式判定，需要单独授权）：
7. 审核人公开盐值，核对其 sha256 与冻结文件一致，不一致就停止（F10）。重新计算 R*、M1* 及其哈希，与冻结文件比对。
8. 生成测试集：
   - seed = int(sha256("E2C-test2|" + salt)) mod 2⁶³，rng = `random.Random(seed)`；
   - 主题面键 = rng.sample(sorted(M1*), 1000)；
   - 每个键：先由 rng.random() < 0.5 决定两条语句的先后，两个查询都用；
   - 换根：对每条语句，把不在题面中的 8 个数字按升序排列后用 rng.shuffle 打乱，取第一个使换根后的键属于 R* 的数字，生成换根题面（语句顺序不变）；没有这样的数字时，该语句没有换根反事实。
9. 序列化 test2，记录 sha256。隔离检查：
   - 全部主题面和反事实的键都属于 R*；
   - 与 E1 各题集的重叠为 0；
   - 与全部 E2-c 种子（以及校准种子）12000 步训练流的重叠为 0。按构造必然为 0，仍要实际核对。
   - 任何一项不为 0 就停止，不判定（F10）。
10. 每个运行判定一次，判定文件只写一次。

**可行性（对任何盐值都成立）**：
- |M1*| = 4,129 ≥ 1000，抽样总能完成。
- M1* 中每个键至少有一条语句能在 R* 内换根，所以换根对数 ≥ 1000（每个题面至少 1 对）。
- 期望换根对数为 1000 × (3,364 × 1 + 765 × 2) / 4,129 ≈ 1,185。
- 是否属于 M1*，取决于相邻键的 sha256，与题面内容无关。所以只从 M1* 中抽样，不会造成内容上的系统偏差。

**封存的含义与限制**：
- 盐值在判定授权之前不公开，所以执行方在判定之前无法生成具体的测试集。
- 但 M1* 只有 4,129 个键，理论上可以在判定前评测整个池。因此另外规定：
  - 阶段 2 只保存哈希，不保存键列表；
  - 只有阶段 2 的哈希脚本和判定脚本可以枚举 R* / M1*；
  - 任何在 R* 内的题面上运行模型的代码路径，在阶段 4 之前都不得执行。
  - 这些规定由冻结清单和运行后审计核对（第 13 节）。
- 如果审核人不提供盐值，就改用固定种子 76000（方案 R）。这时封存只靠哈希承诺和流程审计。

## 12. 潜在混杂、阴性对照与解释限制

### 12.1 潜在混杂与处理

| 混杂 | 处理 |
|---|---|
| 辅助监督本身的一般作用：额外梯度、正则化、防止数字位置表示塌缩 | C2：可学习，监督位置、记录点、条目数、头和损失形式都相同（3.1–3.4） |
| C1 与 C2 的辅助强度不同 | 一次性校准 λ₂，正式运行做能量与裁剪的平衡检查，不平衡就降级（3.5） |
| 辅助任务的难度和学会时刻不同（C2 更容易） | 无法在相同状态上消除（3.2 的证明）；记录各窗口的能量；在解释中标出（12.3）。可选加做 C2-L（D1） |
| 持续不衰减的辅助梯度的作用 | 主设计不检验，可选加做 C3-N（D1） |
| 辅助头增加的参数 | 头固定不训练，C1 与 C2 相同 |
| 优化器状态与梯度裁剪 | 参数层面的范数和裁剪比例都记录；W 内的裁剪比例纳入平衡检查 |
| ACT 动态在条件之间不同 | 主方案只监督总是有效的记录点，被监督条目数相同；ACT 统计逐条件报告（3.3） |
| C2 可能有害（巩固选根），使 C1 对 C2 的差异被夸大 | 判定表要求 P1 也成立；C2 对 C0 单独报告（X7） |
| C2 也保持了可读性 | 特异性检查（5.2），按 7.1 改写结论 |
| λ 的选择偏向结果 | λ 只按可读性、只用非正式种子、按事先固定的规则选择；λ₂ 只按能量选择 |
| 测量用题集沿用 E1 | 它们从未进入训练，也不用于任何判定；判定只用新的 test2（7.4） |
| 种子之间的差异 | 按种子配对；确认性种子事先指定，不挑选 |
| Transformer 的天花板 | 学会速度作为它的次检验（7.2） |
| 多重比较 | 每族用 Holm 校正；次要分析只给名义 p 值 |
| 运行环境变化导致不能逐位复现 | R2；不通过就停止（F2） |

### 12.2 阴性对照

- **C2**：字母内容的阴性对照（可学习、非绑定）。
- **R1′ 分离头**：辅助机制存在、但梯度不回传时，必须与 C0 逐位相同。
- **探针对照**：沿用 E1 的打乱标签对照、同子集 `emb` 控制、植入信号灵敏度。
- **M3 对照**：阴性对照（只交换查询，查询之前的位置不变）和阳性对照（沿用 E1）。
- **正式判定的基准**：50% 是与查询无关策略准确率的上界（同 E1 修订 10.2）。

### 12.3 解释限制

- **只检验充分性**：E2-c 只检验保持线性可读是否改善学习，不检验必要性。即使 C1 改善了学习，也不能说明 C0 的失败是由可读性下降造成的。
- **C1 对 C2 的差异包含两部分**：一部分来自字母对数字的内容差异，另一部分来自辅助任务的难度和学会时刻的差异（3.2）。"绑定特异"的结论应理解为"字母内容的辅助监督，优于在相同状态上、早期强度相当的数字内容辅助监督"，不能理解为"已排除一切难度上的解释"。
- **途径不确定**：C1 的效应即使存在，途径也可能不只是"可读性"。例如辅助任务可能促进了数字位置对本语句字母的注意力，也就是"绑定头"的形成。本设计不区分这些途径，结论表述为"绑定辅助监督"的效应。
- **可读不等于被使用**：线性可读由独立探针在诊断集上测量，并按 E1 的规则判定。它不等于模型实际使用了这些信息。
- **外推范围**：结论只适用于本任务（K=2）、这两个模型规模、这套训练配方和所选的 λ，不外推到 K=4 或更大的模型。
- **不比较架构**：两组分别报告，不判断架构优劣。
- **功效**：功效依赖未知的 C0 学会率和相关结构（4.1）。"不确定"的结论不能解读为"无效"。

## 附录 B：联合功效模拟（设计阶段）

- 运行方式：`python3 -I power.py 20000`，sha256 = `58309e89cf13299aef5373833fa73e726df30b883660469b937b41fb2f4420c0`。
- 输出中的 `excl` 一栏是第一版规则（Newcombe 95% 上限 < 0.30），已经不采用；第二版的规则见附录 C。
- 逐字输出见本附录末尾。

```python
"""Joint power of the E2-c primary family (design analysis only). Per seed the
three paired outcomes (Y0, Y1, Y2) come from a mixture latent model: with
probability rho all conditions share one uniform u (comonotone), otherwise each
condition draws its own u; Y_c = 1[u_c < p_c]. Exact two-sided McNemar per
contrast, Holm over the two contrasts (alpha 0.05), both in the direction C1 >
other. Newcombe (1998, method 10) interval for the paired difference."""
import math, random, sys
from functools import lru_cache
Z = 1.959963984540054
@lru_cache(maxsize=None)
def mcnemar_p(b, c):
    n = b + c
    if n == 0: return 1.0
    k = min(b, c)
    p = sum(math.comb(n, i) for i in range(k + 1)) / 2 ** n
    return min(1.0, 2 * p)
def wilson(x, n):
    p = x / n; d = 1 + Z * Z / n
    c = (p + Z * Z / (2 * n)) / d; h = Z * math.sqrt(p * (1 - p) / n + Z * Z / (4 * n * n)) / d
    return c - h, c + h
@lru_cache(maxsize=None)
def newcombe(a, b, c, d):
    """paired 2x2: a both 1, b first only, c second only, d none; diff = p_first - p_second"""
    n = a + b + c + d
    x1, x2 = a + b, a + c
    p1, p2 = x1 / n, x2 / n
    l1, u1 = wilson(x1, n); l2, u2 = wilson(x2, n)
    den = (a + b) * (c + d) * (a + c) * (b + d)
    phi = 0.0 if den == 0 else (a * d - b * c) / math.sqrt(den)
    dl = math.sqrt(max(0.0, (p1 - l1) ** 2 - 2 * phi * (p1 - l1) * (u2 - p2) + (u2 - p2) ** 2))
    du = math.sqrt(max(0.0, (u1 - p1) ** 2 - 2 * phi * (u1 - p1) * (p2 - l2) + (p2 - l2) ** 2))
    return p1 - p2 - dl, p1 - p2 + du
def sim(N, p0, p1, p2, rho, reps, rng):
    joint = excl = only1 = 0
    for _ in range(reps):
        y = []
        for _ in range(N):
            if rng.random() < rho:
                u = rng.random(); y.append((u < p0, u < p1, u < p2))
            else:
                y.append((rng.random() < p0, rng.random() < p1, rng.random() < p2))
        b10 = sum(1 for a0, a1, _ in y if a1 and not a0); c10 = sum(1 for a0, a1, _ in y if a0 and not a1)
        b12 = sum(1 for _, a1, a2 in y if a1 and not a2); c12 = sum(1 for _, a1, a2 in y if a2 and not a1)
        pa, pb = mcnemar_p(b10, c10), mcnemar_p(b12, c12)
```

```python
"""Boundary error and null power of the 'excludes an increase >= 0.30' claim for
several interval choices (design analysis only; same latent model as power.py)."""
import math, random, sys
def wilson(x, n, z):
    p = x / n; d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d; h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return c - h, c + h
def newcombe_hi(a, b, c, d, z):
    n = a + b + c + d; x1, x2 = a + b, a + c; p1, p2 = x1 / n, x2 / n
    l1, u1 = wilson(x1, n, z); l2, u2 = wilson(x2, n, z)
    den = (a + b) * (c + d) * (a + c) * (b + d)
    phi = 0.0 if den == 0 else (a * d - b * c) / math.sqrt(den)
    du = math.sqrt(max(0.0, (u1 - p1) ** 2 - 2 * phi * (u1 - p1) * (p2 - l2) + (p2 - l2) ** 2))
    return p1 - p2 + du
def run(N, p0, p1, rho, z, reps, rng):
    ex = 0
    for _ in range(reps):
        a = b = c = d = 0
        for _ in range(N):
            if rng.random() < rho:
                u = rng.random(); y0, y1 = u < p0, u < p1
            else:
                y0, y1 = rng.random() < p0, rng.random() < p1
            if y1 and y0: a += 1
            elif y1: b += 1
            elif y0: c += 1
            else: d += 1
        ex += newcombe_hi(a, b, c, d, z) < 0.30
    return ex / reps
```
