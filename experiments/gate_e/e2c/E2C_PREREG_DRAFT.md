## 0. 背景、范围与原则

### 0.1 E1 给出的出发点（探索性观察，不是已证实的结论）

E1（`experiments/gate_e/E1_REPORT.md`）的 K=2 两变量查值任务中：

1. **线性可读性下降早于选根形成**：10 次运行中，数字位置变量字母的线性可读性（P2，线性·标准化探针）持续下降（t_P2lin），都在第 50 或 75 步，早于选根形成 t_R（第 150 步）。两组都是 5/5 一致。
2. **字母敏感性仍在**：所有运行中 t_M3 都未发生，数字位置的状态仍随字母变化（s = 1.000）。K=2 的 MLP 可读性也没有持续下降（t_P2mlp 未发生，10/10）。
3. **选根之后的分化**：所有 K=2 运行都先进入选根阶段，之后出现分化：
   - Transformer 5/5 学会；
   - OpenMythos 2/5 学会，另外 3 个停在与查询无关的选根策略上（test_heldout 准确率约 0.50，查询不敏感率 0.985–1.000）。
4. **第 12000 步的可读性**（描述）：学会的 7 次运行，A_lin 都高于 t_P2lin 门槛；未学会的 3 次都低于门槛。

E1 审核结论：
- 时间先后不能证明可读性下降导致了失败；
- "简单探针读不出来"不等于"信息被删除"；
- 需要研究的是：为什么部分训练轨迹能离开选根阶段，另一些却停在那里。

### 0.2 本实验要回答的问题

在训练中加入一个让数字位置字母信息保持线性可读的辅助任务，是否能让模型更可能、更早地离开选根平台，学会按查询取值？

- E2-c 检验的是一项**具体干预的相对效果**：
  - 字母绑定辅助监督对原始训练（C1 对 C0）；
  - 字母绑定辅助监督对数字编码辅助监督（C1 对 C2）。
- 它不检验必要性，也不能单独确认"保持线性可读性"就是起作用的机制（1.3）。

### 0.3 原则

- **先复现再改进**：
  - 任何干预条件运行之前，先在当前环境中逐位复现 E1 的训练轨迹和诊断数值（第 6 节 R1–R3）；
  - 复现不通过，就停止，不进入干预。
- **上游优先**：
  - 训练数据流、初始化、优化器、学习率计划、batch、步数、留出规则都与 E1 完全相同；
  - 只增加辅助损失，不修改模型架构，不修改 `open_mythos/` 和任何已归档代码。
  - E2-c 的新代码只放在 `experiments/gate_e/e2c/`，以只读方式导入 E1 模块。
- **每阶段结束后停止**：每个阶段结束后停止并等待审核，不自动推进（第 10 节）。
- **不比较架构**：两组分别报告，不据此判断架构优劣。

## 1. 假设、机制与结论的边界

### 1.1 动机性的机制假设（不由 E2-c 单独确认）

要按查询取值，读出位置（`?`，位置 10）必须找到"变量字母与查询字母相同"的那条语句，再取出它的数字。一种可能的实现方式是：

1. **绑定**：数字位置（2、6）的状态中，含有可被线性读取的"本语句的变量字母"；
2. **匹配**：读出位置的注意力用查询字母与这些"字母键"做匹配，从而选中正确的数字；
3. **逃离平台**：匹配一旦形成，梯度就开始支持按查询取值，模型离开"在两个根数字里选一个"的平台。

**机制假设 H**：训练早期，数字位置字母信息的线性可读性下降，使第 2 步缺少可用的"键"，于是选根平台更难离开。

**竞争解释**：
- **A1 伴随现象**：学会与否取决于别的因素，例如梯度对称性的打破（t_G），或注意力路径的形成。
- **A2 一般辅助监督效应**：在数字位置上做任何可学习的辅助监督，都可能通过额外梯度、正则化、防止表示塌缩，或改变优化器状态而影响学习。
- **A3 反方向**：学会导致可读，而不是可读导致学会。
- **A4 其他途径**：字母绑定辅助任务即使有效，途径也可能不是"可读性"本身。例如它可能促进了数字位置对本语句字母的注意力（"绑定头"的形成），或改变了 ACT 的动态。

### 1.2 两类结果必须分开

| 类别 | 问题 | 指标与数据 | 作用 |
|---|---|---|---|
| **操纵检验 H-M**：保持线性可读性 | 干预是否让数字位置的字母保持线性可读？ | 独立探针的 A_lin(t)，在测量用题集上（5.2） | 前提条件，不是正式的学习判定 |
| **结果检验 H-Y**：提高任务学习 | C1 是否比 C0、C2 更多地学会按查询取值？ | 第 12000 步在封存的 `test2_heldout` 上是否"学会"（5.1） | 确认性结论 |

### 1.3 确认性结论能说什么、不能说什么

- **能说**（在 7.1 的判定条件满足时）：
  > 在相同训练配置及预先定义的辅助强度控制下，字母绑定监督（C1）相对于数字编码辅助监督（C2）产生了更大的学习改善，并且相对于原始训练（C0）提高了第 12000 步的学会率。
- **不能说**：
  - "线性可读性是唯一的因果机制"；
  - "线性可读性下降导致了 C0 的失败"。
  - C1 与 C2 之间至少还有三项差异没有被控制：标签熵（约 ln 52 对 ln 10）、任务难度、信息的传递路径（C1 需要从字母位置取回信息，C2 的信息就在本位置）。见 3.2。
- **"排除较大效应"**（7.1）：只有当精确单侧检验在 α = 0.025 下拒绝 Δ ≥ 0.30 时，才能写"与至少 0.30 的提高不相容"。检验不拒绝时写"不确定"，不作否定性结论。
- **机制假设 H**：确认需要另外的实验，例如消除可读性的消融实验，或检验注意力路径的干预。E2-c 的结果只能提高或降低 H 的可信度。

## 2. 任务、模型与训练配方（与 E1 完全相同）

- **任务**：K=2 直接查值，格式 `a=3;b=7;|b?` → `7`。由 `gen_gate_a/levels.py` 的 `_chains_prompt(rng, [1, 1])` 生成。字母在位置 0、4，数字在 2、6，查询字母在 9，读出位置在 10。
- **留出规则**：与 E1 相同。题面的无序语句集合作为键（`e_common.body_key`），sha256 对 10 取余为 0 的题面不进入训练。
  - 训练分布因此与 E1 完全相同，这是逐位复现 E1 的前提。
  - 代价是：可用的未见题面只有这个规则下的留出键（7.4）。
- **模型**：`build(arm, 2)`，不修改。
  - 两组：OpenMythos（T=4，ACT 读出，原生代码）和参数量匹配的 Transformer。
- **训练**：
  - AdamW，学习率 2e-3，按 `budget_a/schedule.extended_lr`（预热 100 步，余弦到第 3000 步，之后保持 2e-4）；
  - 权重衰减 0.1，batch 64，12000 次参数更新；
  - 任务损失只在答案位置计算；
  - 梯度裁剪 1.0，范数只对模型参数计算（与 E1 相同）。
- **初始化**：`torch.manual_seed(seed); build(arm, 2)`。
- **训练数据 RNG**：`random.Random(60000 + seed)`。同一种子下，两组、三个条件的题目序列逐题相同。
- **更新编号**：
  - 参数更新记为 u = 1, …, 12000；第 u 次更新使用训练流中的第 u 个 batch；
  - "第 k 步的 checkpoint"是第 k 次更新之后的参数；第 0 步是初始化。

## 3. 三种条件与辅助监督

### 3.1 条件

| 条件 | 训练损失 | 数字位置上的辅助标签 |
|---|---|---|
| **C0 原始训练** | L = L_task，与 E1 完全相同 | 无 |
| **C1 字母绑定辅助监督** | L = L_task + λ · L_aux | 本语句的变量字母（52 类） |
| **C2 数字编码辅助监督** | L = L_task + λ₂ · L_aux | c(本语句的数字)。c 是从 10 个数字到 52 个类中 10 个类的固定单射，每个种子由 `random.Random(80000 + seed)` 抽取一次 |

- 两种辅助标签都由输入本身决定，不含查询或答案信息。
- 在因果掩码下，两种标签都只依赖数字位置之前（含该位置）的字符。

### 3.2 C2 的选择与设计限制

**为什么不用随机标签**：第一版的 C2 用与输入无关的随机标签，学不会；C1 的字母任务学得会。两者的差异可能只是"可学习"与"不可学习"的差异。

**为什么选数字编码**：它与 C1 有以下相同点：
- 可学习；
- 监督的状态相同：位置、记录点都相同；
- 辅助头和损失形式相同；
- 标签数相同；
- 内容不含字母。

**设计限制**（不是一般性的不可能性证明）：我们没有找到一个与 C1 难度相当、在相同状态上、又不携带本语句字母信息的辅助目标。考察过的候选及其问题如下：

| 候选 | 问题 |
|---|---|
| 本位置数字的函数（即本设计的 C2） | 信息就在本位置，比 C1 容易 |
| 本语句字母的部分信息（例如大小写） | 仍是部分绑定信息 |
| 位置 6 上另一条语句的字母 | 是错误绑定，可能干扰学习 |
| 位置 6 上另一个根数字 | 与选根直接相关 |
| 与输入无关的随机标签 | 学不会 |

这只说明在这些候选中没有合适的。因此 C1 与 C2 之间至少有以下差异没有被控制，在解释中必须标出（1.3、12.3）：
- 标签熵：约 ln 52 对 ln 10；
- 任务难度；
- 信息传递路径：C1 需要注意力从字母位置取回信息，C2 不需要。

**可以加做、但不作为主对照的对照**（D1）：
- **C3-N 随机标签**：用来检验持续不衰减的辅助梯度本身的作用；
- **C2-L 字母在字母位置**：标签内容与 C1 相同，但只监督字母所在的位置。

### 3.3 辅助头、监督位置与 ACT（D3 主方案，已获原则认可）

**辅助头**：
- 每个监督记录点各有一个线性映射 d_model → 52；
- 用独立的 `torch.Generator().manual_seed(90000 + seed)` 初始化，之后固定，不训练；
- C1 与 C2 在同一种子下用逐位相同的头权重，两者都没有额外的可训练参数；
- 头是随机的，所以训练开始时两种辅助损失都约为 ln 52。

**监督位置**：数字位置 2 和 6。

**监督记录点**：只选在 ACT 下总是有效的记录点。
- OpenMythos：`e`、`h1`、`h_out`、`coda_out`；
- Transformer：`out0`、`out1`、`out2`。
- 理由：OpenMythos 的循环里，一个位置停止累计之后，它的状态权重为 0，但仍被同一题中还在运行的位置读取；只有当整个 batch 的所有位置都停止时，后面的循环才被跳过。所以 `h2`–`h4` 是否执行、是否有效，取决于各条件自身的 ACT 动态。而上述 4 个记录点在每一步、每个样本上都存在且有效。
- 不采用包含 `h2`–`h4` 的方案。

**有效性掩码**：恒为 1。C1 与 C2 每一步的被监督条目数完全相同：64 × 2 × 记录点数（OpenMythos 4 个，Transformer 3 个）。

**损失归一化**：
- 每个记录点 r：L_r = 1/(64·2) · Σ_b Σ_{p∈{2,6}} CE(W_r · h_{b,p}^{(r)}, y_{b,p})；
- 总辅助损失：L_aux = (1/R) Σ_r L_r，每个记录点权重相同，R 为记录点数。

**对三个条件公平性的影响**：
- 被监督条目的数量和位置，在 C1、C2 之间逐步相同，与 ACT 动态无关。
- ACT 动态本身可能因条件而不同，例如 `h_out` 的组成会随停止时刻改变。这属于处理效应的一部分。
- 三个条件都记录训练 batch 上的 ACT 统计：每次更新执行的循环数、各轮停止的位置比例。前 1000 次更新每 10 次记录一次，之后每 100 次一次。D2c 检查点上还报告 M6。

**评测**：辅助头只在训练中使用，所有诊断和正式判定都不使用它。

### 3.4 梯度与监督量：能控制什么，不能控制什么

| 量 | 控制方式 | 是否控制 |
|---|---|---|
| 更新次数、batch、学习率计划、优化器、权重衰减、裁剪规则 | 三个条件相同 | **精确控制** |
| 训练题目序列、初始化 | 同一种子下逐题、逐位相同，并核对哈希（3.5） | **精确控制** |
| 被监督的状态：位置、记录点 | C1、C2 相同 | **精确控制** |
| 每次更新的被监督条目数 | C1、C2 相同（掩码恒为 1） | **精确控制** |
| 辅助头（参数量、权重） | 固定不训练，C1、C2 同种子逐位相同 | **精确控制** |
| 损失形式、类别数 | 都是交叉熵，都是 52 类的头 | **精确控制** |
| 早期窗口 W（第 1–300 次更新）内的辅助误差信号能量 | 用 λ₂ 一次性校准，正式运行逐种子核对平衡（3.5） | **近似控制**，有降级规则 |
| W 之后每次更新的辅助梯度大小 | 不配对。C2 可能更早学会，梯度更早衰减 | **不控制**，分窗口记录 |
| 梯度的方向和结构 | 由辅助任务的内容决定 | **不控制**：其中既有内容差异，也有难度差异 |
| 辅助任务的难度和学会时刻 | C2 的信息就在本位置 | **不控制**（3.2 的设计限制） |
| 标签熵（单个数字位置的边际分布） | C1 约为 log 52（字母近似均匀），C2 为 log 10（数字均匀） | **不控制**，只记录 |
| 参数层面的辅助梯度范数，以及它对 AdamW 一、二阶矩的影响 | 定期测量 | **不控制**，只记录 |
| 裁剪生效的比例 | 每次更新记录 | **不控制**，只记录；W 内的差异纳入平衡检查 |
| 辅助内容对表示的副作用 | 用 M1、M3、M6 描述 | **不控制** |

例如，数字编码可能加强数字身份的表示，从而巩固选根策略。这种副作用也属于 C2 对 C0 差异的一部分。

### 3.5 权重、早期窗口、平衡核对、零分母、裁剪与配对完整性

**早期窗口的精确定义**：
- W = 第 u = 1, …, 300 次更新，即训练流中的第 1–300 个 batch；
- r_u 是第 u 次更新所用 batch 上，辅助损失（含权重）对全部被监督状态的直接误差信号的 Frobenius 范数，在裁剪之前计算；
- E_W = Σ_{u=1}^{300} r_u²。
- 校准运行和正式运行用同一定义。正式运行第 301 次及之后的更新不计入 W。

**C1 的 λ**（阶段 1，只用非正式种子，只看可读性）：
- 候选值：λ ∈ {0.03, 0.1, 0.3, 1.0}；
- 校准种子：91、92、93，每组单独选择；
- 校准过程：C1 训练 3000 次更新，checkpoint 取第 0、25、50、75、100、150、200、300、500、1000、2000、3000 步，用 E1 的 `diag_fit` / `diag_eval` 计算独立探针的 A_lin；
- 规则：选最小的 λ，使 3 个校准种子在第 50–3000 步的每个 checkpoint 上都满足 A_lin > 门槛（门槛定义见 5.2）；
- 只看可读性：选择不看任何任务学习指标。校准运行的学习指标照常记录并在审计日志中报告；
- 都不满足时：停止并报告（F4），不扩展候选范围。

**C2 的 λ₂**（一次性校准，不迭代）：
1. 在同样的 3 个校准种子上，C2 先用 λ₂ = λ 训练 300 次更新，得到 E_W^C2(λ)；
2. 取 E_W^C1 为 C1 校准运行在 W 内的能量，按种子取平均；
3. λ₂ = λ · √(E_W^C1 / E_W^C2(λ))，限制在 [λ/10, 10λ] 之内。达到边界时如实报告。
- λ 和 λ₂（每组）写入冻结文件，之后不再改变，也不依据任何后续结果（包括 test2）调整。

**正式运行的平衡检查（BAL）**：

| 条件 | 要求 |
|---|---|
| 能量平衡 | 每个种子计算 B = E_W^C2 / E_W^C1。B 在 [0.5, 2] 之外的种子不超过 25% |
| 裁剪平衡 | W 内裁剪生效的更新比例，C1 与 C2 之差超过 0.20 的种子不超过 25% |

- 两条都满足才算通过。
- 不通过时，依赖 C1 对 C2 比较的结论一律降级为描述性（7.1）。
- 第 301–3000 次和第 3001–12000 次更新的能量比、裁剪比例分窗口报告，不参与判定。

**零分母**：

| 情形 | 规则 |
|---|---|
| 正式运行中 E_W^C1 = 0 或不是有限值 | 实现错误：λ > 0 时，有限 logits 上的交叉熵梯度不可能为 0。完整性失败（F8），停止 |
| 校准中 E_W^C2(λ) = 0 或不是有限值 | 停止（F4） |
| 计算 B 时 E_W^C2 = 0 | B 记为 0，不在 [0.5, 2] 之内，计入平衡检查 |

本设计没有逐步缩放，因此不存在逐步的分母。

**裁剪**：
- 辅助梯度先与任务梯度相加，再按模型参数的总范数统一裁剪到 1.0；辅助头不训练，不参与裁剪。
- 平衡检查用裁剪之前的 r_u。同时记录每次更新的裁剪系数 κ_u，并据此报告"实际更新层面"的辅助能量 Σ r_u² κ_u²。

**配对完整性**：

| 范围 | 核对内容 | 核对方式 |
|---|---|---|
| **C0、C1、C2 三者共同** | 第 0 步的参数 sha256；训练 batch 的哈希链（第 u 次更新所用 batch 的 token 张量计入链式 sha256，每 100 次更新记录一次链值）；学习率计划和优化器设置 | 同一种子的三个条件逐项相等 |
| **只在 C1 与 C2 之间** | 辅助头权重的 sha256（每个记录点）；监督位置和记录点列表；掩码为全 1 | 同一种子的 C1、C2 相等。C0 没有这些项，不核对 |
| **只属于 C1 / 只属于 C2** | C1 的 λ、C2 的 λ₂，与冻结文件一致；C2 的数字编码 c 的 sha256，首次启动时写入运行记录，之后每次启动都由 `Random(80000 + seed)` 重算并比对 | 每个运行单独核对 |
| **每个运行** | r_u、κ_u、ACT 统计的记录，能由同一 checkpoint 和 batch 逐位重算（V1） | 抽查重算 |

任何一项不一致都是完整性失败（F8），停止。

**中断与重跑的一致性**（沿用 E1 12.4.4）：
- 训练运行是原子的：中断后未归档的尝试整体隔离，从第 1 次更新起重新训练。
- 重新训练与被隔离的尝试在重叠部分必须逐位相同，包括 checkpoint、batch 哈希链、r_u 和 κ_u 的序列；不同就是完整性失败（F8）。
- 因此，W 的能量总是由一次完整、连续的训练计算出来，不会出现跨越重启的窗口边界。

**参数层面的记录**：在前 1000 次更新每 10 次、之后每 100 次的记录点，额外反传一次辅助损失并记录 ‖∂L_aux/∂θ‖。
- 用 `autograd.grad`，不累加到参数梯度，不影响训练轨迹（R1″ 验证）；
- 训练耗时约 +2%，已计入预算。

## 5. 指标

### 5.1 任务学习（结果检验 H-Y，正式判定只用 `test2_heldout`）

**目标总体**：M1*，即至少一条语句能在剩余池 R* 内换根的留出键（7.4）。
- 主分析的结论适用于这个总体，而不是全部 6,913 个剩余留出键，也不是 E1 测试集的总体。
- M1* 的筛选取决于题面的邻接结构，对其他总体的代表性没有证明。

**主要指标（每次运行）**：第 12000 步是否"学会"。门槛与 E1 第 5.3 节相同：准确率 ≥ 90%，换根双对率 ≥ 80%，换查询双对率 ≥ 80%。三个量的定义如下：

| 量 | 单位与权重 | 分母 |
|---|---|---|
| 准确率 | 每道主题权重相同，所以每个主题面权重相同（两道题） | 2000 道主题 |
| 换查询双对率 | 每个主题面：两个查询都答对记 1 | 1000 个主题面 |
| 换根双对率（主定义，按题面加权） | 先在每个主题面内，对它的 1–2 个换根对取平均：原题与换根题都答对记 1；再对 1000 个主题面取平均，每个主题面权重相同 | 1000 个主题面（每个至少 1 个换根对） |

- **描述性**：按换根对加权的换根双对率，分母为换根对总数（1000–2000 之间）。
- **置信区间的分组单位**：主题面。每个主题面带着它的两道主题、换查询配对和换根反事实一起重抽。题面分组自助法：2000 次，seed 0。

**重复的反事实**：按 7.4 第 8 步，反事实键优先避开 test2 的主题面和已经用过的反事实；只有在没有其他选择时，才允许重复（"回退"）。
- 报告：回退的换根对数量；与 test2 主题面相同的反事实数量；彼此相同的反事实数量。
- 敏感性分析：去掉全部回退换根对后，重算换根双对率和"学会"判定，只作描述。
- 主分析的分组自助法不刻画回退造成的跨题面相关。回退比例较高时，换根双对率的区间可能偏窄，结论中要注明。

**与 E1 的可比性限制**：以下几点不同，所以 E2-c 的"学会"不等同于 E1 的"学会"，两者的数值不能直接对照，只能描述性并列：
1. 总体：E1 从全部留出键中抽样，E2-c 从 M1* 中抽样；
2. 换根反事实：E1 每道题都有，E2-c 每个题面 1–2 个；
3. 加权：E1 按题平均，E2-c 按题面加权；
4. 反事实选择规则不同（7.4）。

**次要指标**：
- 第 12000 步 `test2_heldout` 上的准确率、换根双对率、换查询双对率、查询不敏感率，以及按 E1 第 5.3、9.5 节的三个等级；
- t_L：在测量用题集 `dev_heldout`（E1 的）的训练日志上，第一个满足"准确率 ≥ 90% 且换查询双对率 ≥ 80%"、并且下一个记录点也满足的步数。
  - 记录频率与 E1 相同：前 1000 次更新每 25 次，之后每 250 次。
  - 到第 12000 次更新仍未发生，记为"未发生"。
  - t_L 依赖测量用题集，是预先登记的次要分析，不作为正式判定（D9）。
- 在测量用题集上计算的 t_R、t_Q、J。

**组间效应**：学会率的配对差 Δ = p(C1) − p(对照)。
- 报告 Newcombe（方法 10）95% 区间，只作描述性估计：附录 C 显示，它在小样本边界上的单侧覆盖不足。
- 确认性推断只用 7.1 的精确检验。

### 5.2 操纵检验（H-M，前提条件，在测量用题集上）

- **A_lin(t)**：数字位置各记录点（不含 `emb`）上，P2 线性·标准化探针准确率的最大值。
  - 定义、代码和判定规则都与 E1 相同；
  - 循环记录点 `h1`–`h4` 用 E1 的 D2-E 单样本有效性语义；
  - 探针在 E1 的 `diag_fit` 上拟合、在 E1 的 `diag_eval` 上评测，与训练用的辅助头无关。
- **门槛**：θ = c₀ + 0.5 · (A_lin(0) − c₀)，c₀ = 1/52。同一种子三个条件的初始化相同，所以 θ 也相同。
- **t_P2lin**：定义同 E1，在 E2-c 的检查点网格上计算。
- **操纵检验通过的条件**（两条都要满足）：
  1. C1 中，至少 80% 的种子 t_P2lin 未发生；
  2. 配对符号检验：C1 在第 50–3000 步各检查点上 A_lin 的最小值，高于 C0 的种子数显著（精确符号检验，双侧 α = 0.05）。
- **前提复现检查**（不是操纵条件）：C0 中至少 80% 的种子 t_P2lin 发生，即在新种子上复现 E1 的现象。
- **特异性检查（SPEC）**：C2 中 t_P2lin 发生的种子 ≥ 80%，即 C2 没有保持字母可读性。
- **描述性的"外溢"**：在 OpenMythos 未被监督的循环记录点 `h2`–`h4` 上，单独报告 A_lin。

### 5.3 诊断（E2-c 精简版 D2c，沿用 E1 已验证的代码和定义；只用测量用题集）

## 7. 统计分析与判定

### 7.1 OpenMythos：确认性主检验族

**优越性检验**（族水平 α = 0.025，Holm 校正；各检验为双侧）：
- P1：C1 对 C0；P2：C1 对 C2。比较的是第 12000 步在 `test2_heldout` 上"学会"的比例。
- 方法：配对精确 McNemar 检验。只用不一致对：b = C1 学会而对照未学会，c = 对照学会而 C1 未学会。它是条件精确检验，在任何参数下实际水平都不超过名义值。
- Holm：两个 p 值中较小的 ≤ 0.0125 时拒绝它；之后较大的 ≤ 0.025 时也拒绝。
- 每个检验的结果记为：
  - **+**：校正后显著，且 b > c；
  - **0**：不显著；
  - **−**：校正后显著，且 b < c。

**排除检验**（一个确认性检验，单独控制）：
- **假设**：H₀：Δ₁₀ ≥ 0.30，对 H₁：Δ₁₀ < 0.30。Δ₁₀ = p(C1) − p(C0) = P(b 类) − P(c 类)。
- **方法**：精确无条件检验，名义水平为单侧 α = 0.025。
  - 统计量：Tango（1998）分数统计量 Z = (b − c − N·0.30) / √(N·(2·p̃_c + 0.30·0.70))。p̃_c 是在 Δ = 0.30 约束下 P(c 类) 的极大似然估计（闭式解，附录 D 已核对）。
  - 拒绝"大"效应的方向：Z 越小，越支持 Δ < 0.30。
- **确认性判定以冻结的拒绝域表为准**：观测到的 (b, c) 在表内就拒绝 H₀，否则不拒绝。表外的 (b, c) 都不拒绝，并且总有 b + c ≤ N。
  - N = 20：b = 0：c ≥ 0；b = 1：c ≥ 0；b = 2：c ≥ 1；b = 3：c ≥ 3；b = 4：c ≥ 4；b = 5：c ≥ 6；b = 6：c ≥ 8；b = 7：c ≥ 9；b = 8：c ≥ 11；b ≥ 9：不拒绝。
  - N = 24：b = 0：c ≥ 0；b = 1：c ≥ 0；b = 2：c ≥ 0；b = 3：c ≥ 1；b = 4：c ≥ 3；b = 5：c ≥ 5；b = 6：c ≥ 6；b = 7：c ≥ 8；b = 8：c ≥ 9；b = 9：c ≥ 11；b = 10：c ≥ 13；b ≥ 11：不拒绝。
  - N = 30：b = 0–3：c ≥ 0；b = 4：c ≥ 1；b = 5：c ≥ 3；b = 6：c ≥ 4；b = 7：c ≥ 6；b = 8：c ≥ 7；b = 9：c ≥ 9；b = 10：c ≥ 11；b = 11：c ≥ 12；b = 12：c ≥ 14；b = 13：c ≥ 15；b ≥ 14：不拒绝。
- **表是怎样得到的**（附录 D）：
  - 在边界 Δ = 0.30 上，取讨厌参数 p_c 的 4,001 个网格点，计算 P(Z ≤ z_obs)，取网格上的最大值作为近似 p 值，再取近似 p 值 ≤ 0.025 的 (b, c)。
  - 网格上的最大值只是下界，不是连续参数上的上确界。所以表的有效性不依赖这一步，而由下一条的认证确立。
- **表的有效性（认证）**（附录 F）：
  - 冻结表关于 b 是递减集：若 (b, c) 在表内且 b ≥ 1，则 (b − 1, c) 也在表内。
  - 在固定 p_c 时把概率质量从"其余"移到 b 类，不会增大递减集的概率（耦合论证）。由此，整个原假设区域上的上确界等于边界上的上确界。
  - 在边界上，拒绝概率是讨厌参数的 N 次多项式。用精确有理数把它写成伯恩斯坦形式，再用分支定界逐段细分，得到有保证的上界：N = 20、24、30 时分别为 0.024263、0.024196、0.020581，都低于 0.025。
  - 审核方用独立的有理数伯恩斯坦上界，得到 0.024787、0.024426、0.022650，结论相同。
  - 对应的单侧覆盖：在 Δ ≥ 0.30 的任何参数下，"不拒绝"的概率至少为 0.9757、0.9758、0.9794。
- **离散小样本处理**：
  - 不使用随机化；
  - 同值的统计量一并计入（取"≤"），检验偏保守；
  - 实际水平低于名义值的部分不作调整。
- **报告的 p 值**：只报告附录 F 算法给出的**认证上界 p̄**，即 {(b′, c′)：Z(b′, c′) ≤ Z(b, c)} 在边界上的概率上确界的有理数上界，向上取整到 6 位小数。
  - 算法的适用条件：所用的 Tango 下集都关于 b 递减。附录 F 已对 N = 20、24、30 的全部下集逐一核对。
  - 与冻结表的一致性：冻结表本身就是 Tango 下集，所以表内任何 (b, c) 的 p̄ 都不超过表的认证水平（< 0.025）。表外的 (b, c)，网格上的 p 值（上确界的下界）已经 > 0.025。因此 p̄ 与表的判定不会矛盾；阶段 1 的 V7 再核对一次。
- **不报告反演置信上界**：把检验对 Δ₀ 取反，需要对每个 Δ₀ 都做认证，并且需要拒绝域随 Δ₀ 嵌套。本版没有经过验证的算法，所以不报告。效应估计只用描述性的 Newcombe 95% 区间（5.1）。
- **Δ₁₂（C1 对 C2）**：同类检验只作描述，给名义结果，不属于确认性检验。

**错误率控制与推断范围**：
- **OpenMythos 的确认性检验共三个**：P1、P2（优越性，Holm，族水平 0.025）和排除检验（α = 0.025）。
  - P2 的零假设（p₁ = p₂）与排除检验的零假设（Δ₁₀ ≥ 0.30）可以同时为真。
  - 由 Bonferroni 不等式，无论哪些零假设同时为真，至少错误拒绝一个零假设的概率都 ≤ 0.025 + 0.025 = 0.05。
  - Holm 在优越性族内是强控制。
- **前提、修饰规则不会增大错误率**：前提条件（操纵检验、无改善空间）和修饰规则（BAL、SPEC、前提复现）只会撤回或改写结论，不会新增被拒绝的零假设，所以不增大上述错误率。
- **方向**：结论的方向按 b 与 c 的大小给出。上述保证针对零假设的错误拒绝；对方向错误不另作族水平的保证。
- **架构之间的推断范围**：
  - OpenMythos（7.1）与 Transformer（7.2）各自是独立的检验族，各自控制族错误率 ≤ 0.05。
  - 不作跨架构的确认性结论：不比较两组，不合并两组，一组的结果不改变另一组的结论。
  - 若同时考虑两组，至少出现一个错误确认性结论的概率按 Bonferroni 不超过 0.10。报告中要写明这一点。

**确定性算法**：

阶段 2（数据准备，需要单独授权）：
1. 读取 E1 的 K=2 题集文件，按 E1 清单核对 sha256，不符就停止。
2. 用 E1 的 `body_key` / `is_heldout` 规则，按规范顺序枚举键空间，得到 H：字母对按 `LETTERS` 顺序取 l₁ < l₂，数字 d₁ ≠ d₂ 按字符顺序。
3. 计算 U、R* = H \ U、M1*（定义同上表）。
4. 核对 |H|、|U|、|R*|、|M1*| 与附录 A 的设计阶段数值（12,006 / 5,093 / 6,913 / 4,129）完全一致；不一致就停止（F11）。
5. 把 R*、M1* 按键字符串排序，各自的规范序列化（每行一个键）的 sha256 写入冻结文件。键列表本身不保存。
6. 盐值承诺（D5，方案 S）：
   - 审核方用密码学安全的随机源生成一个至少 128 位的盐值，例如 `secrets.token_hex(16)` 或更长；
   - 冻结之前只提供 sha256(salt)，写入冻结文件；
   - 盐值在正式判定授权之前不公开，执行方也不索取。

阶段 4（正式判定，需要单独授权）：
7. 审核方公开盐值，核对其 sha256 与冻结文件一致，不一致就停止（F10）。重新计算 R*、M1* 及其哈希，与冻结文件比对。盐值遗失时，不进行正式判定，提交审核；不自动改用其他方案。
8. 生成测试集：
   - seed = int(sha256("E2C-test2|" + salt)) mod 2⁶³，rng = `random.Random(seed)`；
   - 主题面键 = rng.sample(sorted(M1*), 1000)；
   - 按抽样顺序处理每个键：先由 rng.random() < 0.5 决定两条语句的先后，两个查询都用；
   - 换根：对每条语句，把不在题面中的 8 个数字按升序排列后用 rng.shuffle 打乱（每条语句恰好打乱一次），然后按打乱后的顺序：
     - **首选**：取第一个使换根后的键属于 R*，且不属于 test2 主题面、也不是已选反事实的数字；
     - **回退**：没有这样的数字时，取第一个使换根后的键属于 R* 的数字，记为"回退"；
     - 两者都没有时，该语句没有换根反事实。
   - 按 M1* 的定义，每个主题面至少有一条语句能得到换根反事实。
9. 序列化 test2，记录 sha256。隔离检查：
   - 全部主题面和反事实的键都属于 R*；
   - 与 E1 各题集的重叠为 0；
   - 与全部 E2-c 种子（以及校准种子）12000 次更新的训练流重叠为 0。按构造必然为 0，仍要实际核对。
   - 任何一项不为 0 就停止，不判定（F10）。
   - 同时报告回退数量和各类重复。
10. 每个运行判定一次，判定文件只写一次。

**可行性**（对任何盐值都成立）：
- |M1*| = 4,129 ≥ 1000，抽样总能完成；
- 每个主题面至少有 1 个换根对，所以换根双对率的分母是 1000 个主题面。
- 换根对总数的期望约为 1000 × (3,364 + 2 × 765) / 4,129 ≈ 1,185，首选和回退都计入。回退只影响重复，不影响每个主题面至少有 1 个换根对。

**总体与偏差**：
- 是否属于 M1*，取决于相邻键的 sha256 与剩余池的组成。我们不声称这种筛选与题面内容无关，也不声称结果对 R* 或全部留出键无偏。
- 结论的适用总体是 M1*（5.1）。
- 描述性地报告 M1* 与 R* 在字母、数字分布上的差异（只用键本身，不涉及任何模型输出）。

**封存的含义与限制**：
- 盐值在判定授权之前不公开，所以执行方在判定之前无法生成具体的测试集。
- 但 M1* 只有 4,129 个键，理论上可以在判定前评测整个池。因此另外规定：
  - 阶段 2 只保存哈希，不保存键列表；
  - 只有阶段 2 的哈希脚本和判定脚本可以枚举 R* / M1*；
  - 任何在 R* 内的题面上运行模型的代码路径，在阶段 4 之前都不得执行。
  - 这些规定由冻结清单和运行后审计核对（第 13 节）。
- 方案 R（固定种子 76000）只在审核方明确选择时使用。

### 12.2 阴性对照

- **C2**：字母内容的对照（可学习、非绑定）。
- **R1′ 分离头**：辅助机制存在、但梯度不回传时，必须与 C0 逐位相同。
- **探针对照**：沿用 E1 的打乱标签对照、同子集 `emb` 控制、植入信号灵敏度。
- **M3 对照**：阴性对照（只交换查询，查询之前的位置不变）和阳性对照（沿用 E1）。
- **正式判定的基准**：50% 是与查询无关策略准确率的上界（同 E1 修订 10.2）。

### 12.3 解释限制

- **只检验具体干预的相对效果**：E2-c 检验字母绑定辅助监督相对 C0、C2 的效果，不检验必要性。即使 C1 改善了学习，也不能说明 C0 的失败是由可读性下降造成的，也不能确认可读性是唯一机制（1.3、A4）。
- **C1 对 C2 的差异**：它同时包含内容、标签熵、难度和信息路径的差异（3.2）。结论只能表述为 1.3 中的相对效果。
- **可读不等于被使用**：线性可读由独立探针在测量用题集上测量，并按 E1 的规则判定。它不等于模型实际使用了这些信息。
- **总体**：正式判定的总体是 M1*（7.4），不能直接推广到全部留出题面；E2-c 的"学会"与 E1 的"学会"不可直接比较（5.1）。

"""Joint power of the E2-c primary family (design analysis only). Per seed the
three paired outcomes (Y0, Y1, Y2) come from a mixture latent model: with
probability rho all conditions share one uniform u (comonotone), otherwise each
condition draws its own u; Y_c = 1[u_c < p_c]. Exact two-sided McNemar per
contrast, Holm over the two contrasts (alpha 0.05), both in the direction C1 >
other. Newcombe (1998, method 10) interval for the paired difference."""
import math, random, sys
from functools import lru_cache
Z = 1.959963984540054
@lru_cache(maxsize=None)
def mcnemar_p(b, c):
    n = b + c
    if n == 0: return 1.0
    k = min(b, c)
    p = sum(math.comb(n, i) for i in range(k + 1)) / 2 ** n
    return min(1.0, 2 * p)
def wilson(x, n):
    p = x / n; d = 1 + Z * Z / n
    c = (p + Z * Z / (2 * n)) / d; h = Z * math.sqrt(p * (1 - p) / n + Z * Z / (4 * n * n)) / d
    return c - h, c + h
@lru_cache(maxsize=None)
def newcombe(a, b, c, d):
    """paired 2x2: a both 1, b first only, c second only, d none; diff = p_first - p_second"""
    n = a + b + c + d
    x1, x2 = a + b, a + c
    p1, p2 = x1 / n, x2 / n
    l1, u1 = wilson(x1, n); l2, u2 = wilson(x2, n)
    den = (a + b) * (c + d) * (a + c) * (b + d)
    phi = 0.0 if den == 0 else (a * d - b * c) / math.sqrt(den)
    dl = math.sqrt(max(0.0, (p1 - l1) ** 2 - 2 * phi * (p1 - l1) * (u2 - p2) + (u2 - p2) ** 2))
    du = math.sqrt(max(0.0, (u1 - p1) ** 2 - 2 * phi * (u1 - p1) * (p2 - l2) + (p2 - l2) ** 2))
    return p1 - p2 - dl, p1 - p2 + du
def sim(N, p0, p1, p2, rho, reps, rng):
    joint = excl = only1 = 0
    for _ in range(reps):
        y = []
        for _ in range(N):
            if rng.random() < rho:
                u = rng.random(); y.append((u < p0, u < p1, u < p2))
            else:

        b10 = sum(1 for a0, a1, _ in y if a1 and not a0); c10 = sum(1 for a0, a1, _ in y if a0 and not a1)
        b12 = sum(1 for _, a1, a2 in y if a1 and not a2); c12 = sum(1 for _, a1, a2 in y if a2 and not a1)
        pa, pb = mcnemar_p(b10, c10), mcnemar_p(b12, c12)
        both = max(pa, pb) <= 0.05 and min(pa, pb) <= 0.025 and b10 > c10 and b12 > c12
        joint += both
        s1 = (pa <= 0.025 or (pa <= 0.05 and pb <= 0.025)) and b10 > c10
        only1 += s1
        a = sum(1 for a0, a1, _ in y if a1 and a0); d = N - a - b10 - c10
        lo, hi = newcombe(a, b10, c10, d)
        excl += (pa > 0.05 or not (b10 > c10)) and hi < 0.30
    return joint / reps, only1 / reps, excl / reps

"""Exact unconditional test of H0: Delta >= d0 against H1: Delta < d0 for paired
binary outcomes (Delta = p_b - p_c, b = #(C1 learned, C0 not), c = #(C0 learned,
C1 not)), ordered by Tango's (1998) score statistic, p-value = sup over the
nuisance p_c on the boundary Delta = d0. Exact size over the whole null region
and exact power are computed by enumeration (no simulation). Design analysis."""
import math, sys
D0, ALPHA = 0.30, 0.025
def tango_z(b, c, n, d):
    A = 2 * n; B = -b - c + (2 * n - b + c) * d; C = -c * d * (1 - d)
    pc = (math.sqrt(B * B - 4 * A * C) - B) / (2 * A)
    var = n * (2 * pc + d * (1 - d))
    return (b - c - n * d) / math.sqrt(var), pc
def check_mle(n):
    """the closed-form restricted MLE maximizes the likelihood (numerical check)"""
    worst = 0.0
    for b in range(n + 1):
        for c in range(n + 1 - b):
            _, pc = tango_z(b, c, n, D0)
            def ll(q):
                pb = q + D0; r = 1 - pb - q
                if -1e-12 < r < 0: r = 0.0
                if q < 0 or r < 0: return -1e300
                s = 0.0
                for k, p in ((b, pb), (c, q), (n - b - c, r)):
                    if k: s += k * math.log(p) if p > 0 else -1e300
                return s
            grid = max(ll(i / 20000 * (1 - D0) / 2) for i in range(20001))
            assert -1e-12 <= pc <= (1 - D0) / 2 + 1e-12, (b, c, pc)
            worst = max(worst, grid - ll(pc))
    return worst

def pmf(b, c, n, pb, pc):
    r = 1 - pb - pc
    if r < -1e-12: return 0.0
    r = max(r, 0.0)
    lg = math.lgamma(n + 1) - math.lgamma(b + 1) - math.lgamma(c + 1) - math.lgamma(n - b - c + 1)
    t = 0.0
    for k, p in ((b, pb), (c, pc), (n - b - c, r)):
        if k:
            if p <= 0: return 0.0
            t += k * math.log(p)
    return math.exp(lg + t)

    for i in range(grid):

        pb = pc + D0

        # cumulative over ties: P(Z <= z_obs)

            while jj < len(order) and abs(z[order[jj]] - zz) < 1e-12: jj += 1
            cum += sum(probs[j:jj])
            for t in range(j, jj): pval[order[t]] = max(pval[order[t]], cum)
            j = jj
    return {bc for bc in P if pval[bc] <= ALPHA}, pval

    pc = rho * max(p0 - p1, 0) + (1 - rho) * p0 * (1 - p1)

## 附录 F：排除检验的认证上界（第四版）

- 运行方式：`python3 -I certify.py`，sha256 = `3fa03cac4d4ef94c2e2f542a32ccdef07bdd1c6f0b9a7dfc5e15e32313a22718`。全部运算用 `fractions.Fraction` 精确有理数完成。
- 冻结表直接按 7.1 硬编码，不依赖网格代码。
- 认证的内容：
  1. 冻结表关于 b 递减，并且是 Tango 下集；
  2. N = 20、24、30 的全部 Tango 下集都关于 b 递减（这是 p̄ 可以归约到边界的条件）；
  3. 冻结表在原假设区域上拒绝概率的认证上界；
  4. N = 24 时，表边缘内外若干格子的认证 p 值上界 p̄。
- 算法：把边界上的概率写成伯恩斯坦形式，用 de Casteljau 二分做分支定界，直到上界与下界之差 ≤ 1e-7。上界向上取整到 6 位小数。
- 拒绝域判定用表；p̄ 只作报告，二者的一致性见 7.1。

```python
"""Certified (rational-arithmetic) upper bounds for the exclusion test of
PREREGISTRATION 7.1 (design analysis only).
Model: per seed a 3-cell multinomial (b: C1 only learned, c: C0 only learned,
r: rest) with probabilities (p_b, p_c, p_r); Delta = p_b - p_c; H0: Delta >= 3/10.
Reduction to the boundary: if a set A of (b, c) is decreasing in b ((b, c) in A
and b >= 1 imply (b - 1, c) in A), moving probability mass from r to b can only
lower P(A) (coupling: a trial that turns from r into b raises b only). Every
null point (p_b, p_c) is reached from the boundary point (p_c + 3/10, p_c) by
such moves, so sup over H0 = sup over the boundary. On the boundary, with
t in [0, 1]: p_c = 7/20 t, p_b = 3/10 (1 - t) + 13/20 t, p_r = 7/10 (1 - t);
P(A) is a polynomial of degree N in t, written exactly in the Bernstein basis.
The maximum Bernstein coefficient over a subinterval bounds the polynomial
there from above; branch and bound with de Casteljau halving until
upper - lower <= TOL gives a certified upper bound (lower = exact values at
interval ends). All arithmetic in fractions.Fraction."""
import heapq, math
from fractions import Fraction as Fr
TOL = Fr(1, 10**7)
PC, PR, A0, A1 = Fr(7, 20), Fr(7, 10), Fr(3, 10), Fr(13, 20)
TABLE = {  # frozen rejection regions of PREREGISTRATION 7.1: b -> c_min (and b + c <= N)
    20: {0: 0, 1: 0, 2: 1, 3: 3, 4: 4, 5: 6, 6: 8, 7: 9, 8: 11},
    24: {0: 0, 1: 0, 2: 0, 3: 1, 4: 3, 5: 5, 6: 6, 7: 8, 8: 9, 9: 11, 10: 13},
    30: {0: 0, 1: 0, 2: 0, 3: 0, 4: 1, 5: 3, 6: 4, 7: 6, 8: 7, 9: 9, 10: 11, 11: 12, 12: 14, 13: 15},
}
def region(n): return {(b, c) for b, cm in TABLE[n].items() for c in range(cm, n - b + 1)}
def decreasing_in_b(A): return all((b - 1, c) in A for (b, c) in A if b >= 1)
def bernstein(A, n):
    coef = [Fr(0)] * (n + 1)
    for b, c in A:
        r = n - b - c
        K = Fr(math.factorial(n), math.factorial(b) * math.factorial(c) * math.factorial(r)) * PC ** c * PR ** r
        for k in range(b + 1):
            coef[c + k] += K * math.comb(b, k) * A0 ** (b - k) * A1 ** k / math.comb(n, c + k)
    return coef
def halve(cf):
    left, right, cur = [cf[0]], [cf[-1]], cf[:]
    while len(cur) > 1:
        cur = [(cur[i] + cur[i + 1]) / 2 for i in range(len(cur) - 1)]
        left.append(cur[0]); right.append(cur[-1])
    return left, right[::-1]
def certified_sup(cf):
    lower = max(cf[0], cf[-1]); heap = [(-max(cf), 0, cf)]; k = 0
    while True:
        ub = -heap[0][0]
        if ub - lower <= TOL: return lower, ub
        _, _, c0 = heapq.heappop(heap)
        for part in halve(c0):
            lower = max(lower, part[0], part[-1]); k += 1
            heapq.heappush(heap, (-max(part), k, part))
def tango_z(b, c, n, d=0.3):
    A = 2 * n; B = -b - c + (2 * n - b + c) * d; C = -c * d * (1 - d)
    pc = (math.sqrt(B * B - 4 * A * C) - B) / (2 * A)
    return (b - c - n * d) / math.sqrt(n * (2 * pc + d * (1 - d)))
def up6(x): return math.ceil(x * 10**6) / 10**6
for n in (20, 24, 30):
    R = region(n)
    lo, ub = certified_sup(bernstein(R, n))
    # every lower set of the Tango ordering must be decreasing in b (p-value sets)
    cells = [(b, c) for b in range(n + 1) for c in range(n + 1 - b)]
    z = {bc: tango_z(*bc, n) for bc in cells}
    zl_ok = all(decreasing_in_b({x for x in cells if z[x] <= z[bc] + 1e-12}) for bc in cells)
    # the frozen region is a lower set of the Tango ordering
    zmax_in = max(z[x] for x in R); is_lower = R == {x for x in cells if z[x] <= zmax_in + 1e-12}
    print(f"N={n}: |R|={len(R)} R decreasing in b: {decreasing_in_b(R)}; R is a Tango lower set: {is_lower}; "
          f"all Tango lower sets decreasing in b: {zl_ok}; certified sup over H0 of P(reject) in "
          f"[{float(lo):.7f}, {float(ub):.7f}] -> certified upper bound {up6(float(ub)):.6f} (nominal 0.025)", flush=True)
# certified p-value upper bounds for N = 24 at the edge cells of the table and just outside it
n = 24
cells = [(b, c) for b in range(n + 1) for c in range(n + 1 - b)]
z = {bc: tango_z(*bc, n) for bc in cells}
for bc in ((0, 0), (2, 0), (3, 0), (3, 1), (5, 5), (5, 4), (10, 13), (10, 12), (11, 13)):
    A = {x for x in cells if z[x] <= z[bc] + 1e-12}
    lo, ub = certified_sup(bernstein(A, n))
    print(f"N=24 (b,c)={bc}: in frozen table {bc in region(n)}; certified p-value upper bound {up6(float(ub)):.6f} (sup in [{float(lo):.7f}, {float(ub):.7f}])", flush=True)
```
