# ACT-002 · Same-weight counterfactual dynamics

## Why

ACT-001 found that OpenMythos's original ACT recurrence can exit at the
configured maximum depth before probability mass reaches 1. With a candidate
final-remainder rule, the model's logits and training gradients can differ.

ACT-002 separates *current ACT policy* from *previous optimizer updates*.
Neither policy is assumed better. This study operates on synthetic tokens
and randomly initialized tiny models, not real language-model quality.

## 2 × 2 forward passes on the same batch, before each update

| Parameter snapshot | Original ACT | Forced final remainder |
| --- | --- | --- |
| Original-trained parameters (theta_O) | OO | FO |
| Forced-trained parameters (theta_F) | OF | FF |

The **two actual training arms** are OO and FF. FO and OF are read-only
counterfactual forwards, and never update model parameters.

For logits (and separately for cross-entropy losses):

- **Direct ACT mechanism at original weights:** FO − OO
- **Parameter-history effect under original ACT:** OF − OO
- **Policy-by-parameter interaction:** FF − OF − FO + OO
- **Total deployed contrast:** FF − OO

Their *signed tensor values* sum exactly, up to floating-point error.
The magnitudes (L2 norms or maximum absolute values) **do not sum**.
The three-effect decomposition is anchored at original parameters; there is
no unique, universal percentage attribution when interactions are present.

No gradient is computed during FO/OF counterfactual passes. OO and FF perform
ordinary training updates using matched initialization, batches, optimizer
settings and step counts. The script reports the deployed gradient difference.

## Run (Codespaces / CPU)

From the repository root:

```bash
git pull --ff-only origin mini-mythos-research
python -m unittest discover -s research/mini_mythos/tests -p 'test_*.py' -v

python research/mini_mythos/scripts/act_counterfactual.py \
  --repo . --device cpu --attentions gqa --depths 2 \
  --seed 22 --steps 30 \
  --out research/mini_mythos/results/act002_gqa_seed22.json
```

Repeat with `--attentions mla` for MLA, with a different `--out` path.

The report's `results[].train_trace[]` contains all four-cell effects,
original-policy ACT mass for each parameter snapshot, actual loop counts,
gradient delta and pre/post-update parameter delta. `results[].events`
reports first detected mass deficit, mechanism effect, parameter divergence,
and interaction. `results[].heldout` provides four-cell loss comparisons
on the same three synthetic heldout batches.

## Interpretation and controls

- Same-weight FO versus OO isolates the current ACT rule at theta_O; it does
  not measure how a model would perform after retraining under that rule.
- The history term reflects **parameter differences produced by prior updates**;
  the interaction reports dependence of policy effect on parameter state.
- The heldout evaluation is very small; do not claim generalization or
  significance. Use multiple seeds and realistic datasets for broader claims.
- Numerical `first_*` event thresholds are diagnostic, not statistical tests.
- Upstream `open_mythos/main.py` remains unchanged. A temporary forward hook
  changes only the final ACT probability during counterfactual/forced calls.
  The experiment stops if the upstream ACT implementation changes.
- Fixed seeds and `dropout=0` minimize unrelated stochastic effects.
- GitHub Actions runs a short (`--steps 4`) variant for each attention type;
  this is a correctness smoke, not the full 30-step research run.
