# Stage 2:GPU 试点(方案草案,待批准)

规则见根目录 `CLAUDE.md`(宪章 v2.0)。前置条件:阶段 1 修订 1 补跑通过,负责人宣布阶段 1 CLOSED。本阶段**不加任何机制**,只验证 GPU 上的工具链,并测出两个后续必需的量:训练噪声下限和真实成本。

## 目的

1. **GPU 与 CPU 一致**:在 GPU 上复现阶段 1 的原生基线,确认换硬件不改变结论。
2. **实测成本**:训练与评估的 tokens/s、显存、每次实验的美元成本。用它替换简报里按 FLOPs 推算的估计。
3. **跑通“同预算、不加机制”的微调对照**:这是以后每个机制都要比较的对象。先确认训练流程正确、能断点续训,并测出**训练噪声下限**,即只换训练种子时开发集分数波动多大。之后机制带来的改善必须明显大于这个波动,才算数。

## 设置

**机器**:单卡,A100 40GB 或 RTX 4090 24GB 级别。按需租用(RunPod、Vast、Lambda 等,由负责人选择)。

**环境**:Python 3.12.3,torch 2.11.0 的 CUDA 版本(单独的锁定文件,首次安装时生成并提交)。上游 Parcae `69284c13`,权重 `parcae-140m@236739ce`。训练语料和评测集在 GPU 机器上按阶段 1 修订 1 的 `data_lock.json` 重建,并核对 `manifest.json` 一致。

**评估**:FP32,关闭 TF32,深度 8,不加 BOS,只用开发集(400 个窗口,2 个副本)。测试集本阶段不用。

**训练对照**(都是“不加机制”):
- **C-LoRA**:冻结原模型,在所有 attention 和 MLP 的线性层加 rank 8 的 LoRA。这是以后机制对照的默认形式,参数量可以调到和机制一致。
- **C-Full**(参照):全参数微调,低学习率。用来看“所有参数都可训练”时的上限和风险(比如遗忘)。

**训练方式**:
- 沿用 Parcae 自己的训练设置:bf16 混合精度,每步递归 8 轮,只对后 4 轮反传(与原训练的 `mean_backprop_depth=4` 一致)。
- 序列长 1024,打包方式与原训练相同:不加 BOS/EOS,best-fit。
- AdamW,学习率预热后余弦衰减。学习率只在开发集上搜 3 个值,这个次数会写入以后的同预算规则。
- 每个配置训练 2000 万 token,用 2 个训练种子。

**断点续训**:同一配置中途停下再续训,与不中断的结果比较。开启确定性算法时应逐位一致;做不到的话,开发集分数差必须小于训练噪声下限,并如实报告。

## 验收

1. **GPU/CPU 一致**:同一开发窗口上,GPU(FP32)与阶段 1 CPU 的 NLL 差,平均绝对值 < 0.001,最大 < 0.01。另外报告 bf16 评估与 FP32 的差别,只报告,不作门槛。
2. **成本实测**:报告训练和评估的 tokens/s、峰值显存、每 1000 万训练 token 的美元成本。
3. **训练对照**:C-LoRA 和 C-Full 各 2 个种子,报告每个领域开发集 NLL 的“训练后减训练前”。**训练噪声下限**取同一配置两个种子之差。这里不预设训练一定变好:训练语料来自预训练数据,改善可能很小,也可能在异领域变差。
4. **断点续训**:满足上面的一致性要求。

## 预算与停止条件

- 预计 GPU 时间约 4–6 小时:环境、数据重建、评估各约 0.5 小时;训练约 12 次,每次 10–20 分钟。
- **建议上限 20 美元**,超出就停下报告。
- GPU/CPU 一致性不通过,先停下排查,不往下训练。
- 路径或导入问题 30 分钟内修不好,就停下报告。

## 执行方式

我把所有步骤写成一个脚本 `run_stage2.sh`,在 GPU 机器上一条命令跑完,结果自动提交到本分支。开始前会先在 CPU 上用随机小模型把训练、续训、评估的代码跑通,不在 GPU 上调试。

在 GPU 机器上需要你做的事:
1. 开一台机器;
2. 配好 GitHub 推送权限;
3. 粘贴一条命令。

如果 GPU 机器上也装 Claude Code,也可以交给它执行。

## 需要负责人决定

1. **GPU 平台和卡型**:推荐 RunPod 或 Vast 上的 A100 40GB(按小时计费,单价约 1–1.5 美元)。预算更紧的话,用 RTX 4090(单价约 0.4–0.7 美元)也够。
2. **预算上限**:是否同意 20 美元?
3. **是否保留 C-Full**:它让总时长增加约三分之一,但能告诉我们“全量微调能做到什么程度”,我建议保留。
