# thermo-growth:边读书边生长(Parcae 上的探索),以及收尾对照

规则见根目录 `CLAUDE.md`。本目录是探索性工作:2026-11-09/10 的结果在 `results/cpu_20261109/SUMMARY.md`,都是 CPU 上的小规模结果(20 本书、单一书集),**不是确认性结论**。

## 这里有什么

- **机制**(`knowledge_space.py`、`grow.py`):Parcae 读书时,在“可重复的预测误差”超过噪声的地方,自己长出一个新方向(所有层共用一个逐步变大的子空间)。
- **防遗忘**(`--anchor`):读书时要求预测不偏离原生模型太远(对原生模型的 KL)。这是持续学习里的常规做法,不是新方法。
- **冷却**(`--crystallize`):新方向长出后逐步冻结。
- **稳定性检查**(`--norm-limit`):原生 Parcae 的循环计算在少数输入上会自己发散;检查让模型不去模仿发散的原生输出,并限制隐藏状态放大。
- 已知结果:不加保护时原有知识掉 30%;解冻 + 防遗忘强度 3 掉约 2.6%,对没读过的同类书好约 12%。但约 88% 的进步是“更会读这类书”(领域适配),每本书自己留下的只有约 0.025 nats。

## 收尾对照(方案,2026-11-10,运行前写定)

负责人 2026-11-10 决定:Parcae 不再作为主基底(许可证未确认、循环会发散、预训练弱)。在封存前只回答一个问题,用来决定哪些机制值得移植到新基底:

> **“自己长出新方向”这个机制,本身有没有用?**

### 设置

全部:防遗忘强度 3、稳定性检查 1.5、20 本书 × 16384 词元、读一遍、CPU。

| 组 | 底座 | 新方向 |
|---|---|---|
| `U_none` | 解冻(学习率 1e-5) | 没有 |
| `U_auto` | 解冻 | 在意外处自己长(冷却 12 页) |
| `F_auto` | 冻结 | 在意外处自己长(冷却 12 页) |
| `F_static` | 冻结 | 一开始就给满同样数量,方向随机,全程可学(不冷却) |
| `F_sched` | 冻结 | 同样数量,按固定间隔长出(冷却 12 页) |

- `F_static`、`F_sched` 的方向数取同一书集 `F_auto` 最终长出的数量。
- `F_static` 不冷却:否则它的全部方向会在读完 3 本书后一起冻结,对照就没有意义。
- **两个互不重叠的书集** A、B(各 20 本读 + 10 本从不读),取自 PG-19 同一分片,都与全部评测窗口无 13-gram 重叠。之前换“种子”只改变循环的随机起点,结果几乎一样,所以这次用换书来重复。
- 测量加密:每本书留 8 个窗口不读(之前 2 个),从不读的书每本 4 个窗口。

### 指标

- **没读过的书的进步** H:10 本从不读的书上,原生 NLL − 模型 NLL。
- **每本书自己留下的** S:这本书留出部分的进步,减去同一时段里从不读的书的进步,从读它之前算到全部读完(`grow.specific`)。
- **遗忘** F:c4 / wikitext / fineweb 上 NLL 的平均上升;另报每 10 本书的上升斜率。
- 只报告:即时预测进步、读书时模型独有的发散段数、最终发散的窗口数(与原生对比)。

### 判定(运行前写定)

“更好”= S **或** H 高出 ≥ 0.010 nats,且 F 多出不超过 0.005 nats;**两个书集都成立**。

1. 解冻时:`U_auto` 比 `U_none` 更好。
2. 冻结时:`F_auto` 比 `F_static` 更好。

- 1 成立 → 生长机制随防遗忘、稳定性检查一起移植。
- 只有 2 成立 → 生长只在底座冻结时有用;移植防遗忘和检查,生长不进默认方案。
- 都不成立 → 不移植生长,只移植防遗忘和检查。

`F_sched` 对 `F_auto`(触发时机有没有用)只报告,不参与判定。

### 算力与停止条件

本机 CPU,10 次运行,每次约 30 分钟,共约 5 小时;不用 GPU,不碰测试集。超过 8 小时就停下报告。读书时出现非有限损失就停。

## 文件

| 文件 | 作用 |
|---|---|
| `books.py` | 从 PG-19 选书(去硬换行、与评测窗口去重)、留出部分、从不读的书 |
| `knowledge_space.py` | 共用子空间、意外的度量、长出新方向 |
| `grow.py` | 读书循环、防遗忘、冷却、稳定性检查、各项检查与指标 |
| `compare.py` | 多次运行并排汇总 |
| `closing.py` | 收尾对照的表格与判定 |
| `stability_scan.py` | 逐窗口检查最终模型是否发散 |
| `anneal_split.py` | “降温自发分裂”演示(不训练) |
| `run_growth_cpu.sh`、`run_closing_cpu.sh` | 本机运行脚本 |
| `test_growth.py`、`test_anneal_split.py` | 测试(CPU) |
