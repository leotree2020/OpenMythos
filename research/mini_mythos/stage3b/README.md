# Stage 3b:解冻试点(MoDA-P + 全参数训练)(方案草案,待批准)

规则见根目录 `CLAUDE.md`(宪章 v2.0)。前置:阶段 3a CLOSED(FAIL)。负责人 2026-11-09 决定转向解冻。机制背景见 `../MECHANISMS.md`。

此前的冻结版 3b(深度 LoRA)方案已暂停,原文在 git 历史 `efab8cc6` 中。

## 目的

回答一个问题:**3a 里 MoDA 几乎没被用上,原因是不是原权重被冻住了?**

做法:原权重和 MoDA 一起训练,对照组是同样解冻、同样数据、但不加 MoDA 的模型。

**大白话**:3a 像是给一台已经装好的机器外挂一个零件,机器本身不能动,所以零件几乎没派上用场。这次让机器和零件一起调整,看零件能不能真正接进去。为了公平,对照组的机器也一起调整,也多给它一组同样大小的可调零件,只是这组零件没有“翻旧笔记”的功能。

## 设置

| 组 | 原权重 | 额外零件 | 可训练参数 |
|---|---|---|---|
| N 原生 | 不训练 | 无 | 0 |
| **C 对照** | 全部解冻 | LoRA r28(全层,B 初始为 0) | 144.3M + 2,325,624 |
| **M 机制** | 全部解冻 | MoDA-P(同 3a,门控初始为 0) | 144.3M + 2,359,308 |

- **为什么对照也加 LoRA**:让两组可训练参数相同(宪章 3.4),并且都有一组“初始为 0、用较大学习率”的新参数。这样 M 胜出就不能归因于“多了一组高学习率参数”。
- **起点相同**:两组开始时都和原生 Parcae 逐位相同。

**学习率**:
- 原权重的学习率在 3e-6、1e-5、3e-5 中选。阶段 2 的全参数训练里 1e-5 最好,1e-4 会遗忘。两组都搜这 3 个值。
- 额外零件的学习率固定,沿用 3a 各自选出的值:MoDA 3e-4,LoRA 1e-4。本阶段不再搜。

**训练量**:
- 学习率搜索用 5000 万 token 的短跑,只跑 seed 0;
- 选出学习率后,每组用 **2 亿 token** 正式训练,跑 seed 0 和 1。

其余设置同 3a:bf16、序列长 1024、全局批 32、8 轮且后 4 轮反传、AdamW、预热加余弦、梯度裁剪 1.0。

## 数据:扩充训练语料(评测集不变)

阶段 1 的训练语料只有 5000 万 token,需要扩到约 2.2 亿:
1. **来源不变**:同一个锁定来源(FineWeb-Edu sample-100BT,阶段 1 `data_lock.json` 里的版本),接着阶段 1 已用文档之后往下读。
2. **去污染**:新文档逐篇和全部 1200 个评测窗口做 13-gram 比对,有重叠的**丢弃训练文档**,评测集一个窗口都不动。生成新的 manifest(sha256)和污染报告。
3. **打包改为“保留余量”**:截断后的余量作为新文档放回缓冲区,语料用满。3a 的做法只用上 48%。
4. 语料在 GPU 机器上按确定的流程重建,并按 manifest 核对。CPU 上先用合成数据测试这套流程。

## 评估与通过标准(沿用 3a 的冻结模板,看结果前冻结)

- **评估**:FP32,深度 8,不加 BOS,2 个副本。开发集每领域 100 个窗口,测试集每领域 200 个窗口。
- **主指标**:测试集上逐窗口配对的 `M − C`。
- **开发集关口**:两个种子下,M 在异领域(books、c4、wikitext)的平均开发集 NLL 都低于 C。不过就判 FAIL,测试集不用。
- **测试集**:冻结 M、C 各一个候选(选中学习率,seed 0,2 亿 token),各评一次,记入 `TEST_LOG.md`。这是测试集第二次被用于机制比较,报告中注明。PASS 需同时满足:
  1. 3 个异领域里至少 2 个满足:`M − C` ≤ −0.003,且 CI 上界 < 0;
  2. 异领域平均 `M − C` ≤ −0.003;
  3. 没有领域明显变差,即 CI 下界 > 0 且均值 > +0.003 的领域一个都没有;
  4. 开发集上,两个种子的 `M − C` 都为负,且都大于训练噪声下限。

**只报告、不作门槛的项目**:
- **MoDA 是否被用上**:门控大小、深度输出占注意力输出的比例。3a 冻结时约 1.5%。这是本试点最重要的诊断;
- `M − N` 和 `C − N`:解冻训练相对原生是进步还是遗忘;
- 深度 16 的开发集分数;
- 学习率短跑的全部结果。

## 预算与停止条件

- **总训练量**:6 次短跑 × 5000 万 + 4 次正式 × 2 亿 = 11 亿 token。
- **时间**:
  - 4090:全参数训练约 4.5 万 tokens/s,约 6.8 小时;
  - A100:估计约 5.2 万 tokens/s,约 5.9 小时。
  - 加上数据重建和评估,总共 7–8 小时。
- **费用**:4090 约 $5–6,A100 约 $9–13。**建议上限 $15。**
- **`PRICE_PER_HOUR` 要设成实际单价。**
- **磁盘**:每次训练只保留最新的检查点,训练结束后删除检查点,只留最终参数(每次约 0.6 GB)。Container disk 50 GB 够用。
- **停止条件**:
  - CPU 测试不过,不开机;
  - GPU 上与原生不一致、或 MoDA 初始与原生不一致,就停;
  - 数据 manifest 对不上,就停;
  - 路径或导入问题 30 分钟修不好,就停;
  - 花到上限,就不再开始新训练。
