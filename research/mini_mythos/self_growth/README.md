# 自生长支线:举一反三,而不是死记(方案 v0.1,2026-11-10)

**状态**:独立支线,负责人 2026-11-10 批准。本支线**不使用 Parcae**,与宪章第 1 条不同,所以不属于 Mythos 主线;宪章的其余要求(先写方案、同预算对照、新数据、如实标注)照常适用。

## 目的

检验负责人的想法:模型读到一小块知识后,**自己写出由此能推出什么**(举一反三),再学自己写的内容,一轮轮扩散。要回答的问题只有一个:

> 同样的种子知识、同样的训练量下,“学种子 + 学自己写的推论”是否比“只学种子原文(死记)”更能答对**没有直接教过**的问题?

不设判断对错的裁判:推论由模型看着种子自己写,写成什么就学什么;我们只测量结果。

## 模型

`Qwen/Qwen3-1.7B@70d244cc`(Apache-2.0),本机 CPU,思考模式关闭。体检通不过就换更大的模型,不在这个模型上硬做。

## 数据(`world.py`,由一个整数种子生成,模型不可能见过)

- 虚构世界 Veltar:32 个人、8 个行当、8 个行会、8 个镇。
- **种子**共 88 条,每条一两句话:
  - K1 规则 + 实例:“每个玻璃匠都宣誓加入红鹭行会。某人是玻璃匠。”
  - K2 师承:“某人由某人带出师。”
  - K3 出生地:“某人出生在某镇。”
- **题目**共 168 道,四选一,瞎猜 25%:
  - R 记忆(88 道):种子里直接写着的;
  - I 推一步(32 道):某人属于哪个行会——种子里没直接写,要用同一条种子里的规则推;
  - C 连两条(48 道):“带某人出师的那个人出生在哪个镇 / 属于哪个行会”——要把两条种子连起来。
- 选项里总包含“本人自己的镇/行会”,它一定不是答案,所以“答成本人”会被看出来。各答案出现次数均衡,正确选项的位置在 A–D 间轮换。
- **开发世界**(种子 100):体检和调参用。**测试世界**(种子 0):只在正式比较时用一次。
- **通用能力**:阶段 1 开发集 c4 / wikitext / fineweb 各 25 个窗口上的 NLL,看训练后掉了多少。
- 打分不用裁判:把题和四个选项给模型,直接读出下一个词元是 A/B/C/D 的概率(`lm.py`)。

## 第 1 步:体检(`checkup.py`,不训练,开发世界)

| 检查 | 关口(运行前写定) |
|---|---|
| 闭卷(不给种子):R、I、C 每类正确率 | ≤ 0.40(接近瞎猜,证明知识确实没见过) |
| 开卷(题目需要的种子 + 4 条无关种子放在提示里):R | ≥ 0.90 |
| 开卷:I | ≥ 0.75 |
| 开卷:C | ≥ 0.60 |
| 给一条 K1 种子让它写推论:写出“某人属于某行会”的比例(16 条) | ≥ 0.50 |
| 给两条相连的种子让它找联系:写出“学徒—师傅出生地”这一联系的比例(16 对) | ≥ 0.50 |
| 给两条不相连的种子:回答 NONE 的比例(8 对) | ≥ 0.50 |
| 写出的全部句子里,与世界事实不矛盾的比例(字符串核对) | ≥ 0.80 |

全部满足为 PASS,进入第 2 步;否则 FAIL,报告后换更大的模型。提示语里不出现题目和答案(`derive_prompt` / `connect_prompt`)。

### 体检结果(2026-11-10,Qwen3-1.7B,开发世界):FAIL(8 项里 1 项没过)

| 检查 | 结果 | 关口 | |
|---|---|---|---|
| 闭卷 R / I / C | 0.27 / 0.34 / 0.31 | ≤ 0.40 | 过 |
| 开卷 R | 1.00 | ≥ 0.90 | 过 |
| 开卷 I | 1.00 | ≥ 0.75 | 过 |
| 开卷 C | 0.77(C1 0.88,C2 0.67) | ≥ 0.60 | 过 |
| 一条种子 → 写出该推出的结论 | 0.81 | ≥ 0.50 | 过 |
| **两条相连的种子 → 写出联系** | **0.00** | ≥ 0.50 | **没过** |
| 两条不相连的种子 → 回答 NONE | 1.00 | ≥ 0.50 | 过 |
| 写出的句子不与事实矛盾 | 1.00 | ≥ 0.80 | 过 |

- 没过的一项:16 对相连的种子里,14 对它回答 NONE,另 2 对只把两句话各重复一遍,没有一次写出“学徒的师傅出生在某镇”。可是开卷直接问它时,C 类题能答对 77%。**被问到时会连,自己不会主动去连。**
- 字符串核对很粗:它查不出模型给单条种子添的枝叶(例如“制革是 Veltar 的神圣行当”)。“不矛盾 1.00”只说明没有把镇和行会安错人。
- 原始输出在 `results/checkup_qwen3_1.7b/`。
- 后续:`connect_probe.py` 在开发世界上试几种同样通用的问法(`world.CONNECT_VARIANTS`)和模型的思考模式,关口数值不变,用来分清是模型太小还是问法的问题。

### 探查结果(2026-11-10,`connect_probe.py`,开发世界全部 24 对相连 + 8 对不相连)

“连对 / 连错”是**人工逐句读出来的**:自动的字符串核对只看学徒的名字和师傅的出生地是否出现在同一句里,会把说错的句子也算进去。

| 问法 | 相连的 24 对:连对 | 连错 | 不相连的 8 对:回答 NONE |
|---|---|---|---|
| v1 原问法(体检用的,16 对) | 0 | 0 | 8 / 8 |
| v2 去掉 NONE 退路 | 3(12.5%) | 6(25%,编出“在某镇受训”) | 0 / 8 |
| v3 先说共同点再组合 | 11(46%) | 1 | 1 / 8 |
| v1 + 思考模式 | 640 个词元内没写出答案,在思考里来回绕 | — | — |

- v3 连对的多数是把两句话正确地并成一句(“乙出生在某镇,甲由乙带出师”),少数是真正的推论(“甲由出生在某镇的乙带出师”)。
- v3 对不相连的两条不再回答 NONE,但写的多是无害的重复或“两人出生在不同的镇”,偶尔编出不存在的联系。
- 结论:Qwen3-1.7B 在最好的问法下接近但没达到关口(46% < 50%,NONE 12.5% < 50%);开思考模式在 CPU 上既慢又没有产出。**体检结论仍是 FAIL,第 2 步不在这个模型上做**,等换到 8B 级模型(需要 GPU,负责人批准)再做体检。
- 之后要改进:核对函数要能分辨“说对”和“说错”(现在不能);NONE 的判定已改为“任意一行是 NONE”(`world.says_none`)。
- 原始输出在 `results/connect_probe_qwen3_1.7b/`。

## 第 2 步:三组对比(体检通过后运行)

| 组 | 学什么 |
|---|---|
| A 死记 | 只学种子原文 |
| B 举一反三 | 种子 + 第 1 轮推论(每条种子各写几句) |
| C 多轮扩散 | B + 第 2 轮(把提到同一个名字的两条知识放在一起,让模型写联系)+ 第 3 轮(推论再生推论);LoRA 的秩逐轮长大 |

- **同预算**:三组最终可训练参数量相同(LoRA 最终秩相同)、训练的 token 遍数相同、学习率等的搜索次数相同;搜索只在开发世界上做。每组 2 个训练种子。
- **主指标**:测试世界上,闭卷的 I + C 正确率(80 道)。
- **通过标准(运行前写定)**:
  1. “举一反三有效”:B 或 C 组的主指标比 A 组高 ≥ 15 个百分点,两个训练种子都成立;
  2. 该组的 R 正确率不比 A 组低 5 个百分点以上(推论不能把原文挤掉);
  3. 该组的通用文本 NLL 相对原模型上升 ≤ 0.03。
  三条都满足为 PASS。
- **次要问题**“多轮扩散有额外作用”:C 组在 C 类题上比 B 组高 ≥ 10 个百分点,两个种子都成立。
- **只报告**:
  - 组合题里,答案被某句推论写出来过的、和没被写出来过的,分开算正确率(学到的是推论本身,还是组合的能力);
  - 每一轮推论的不矛盾比例和不重复比例(有没有越扩越偏、越来越单一);
  - 各组的训练曲线和开卷上限。
- 第 2 步的具体超参数(学习率、遍数、每轮写几句)在开发世界上定好、写进本文件后,再跑测试世界。

## 算力、时间上限与停止条件

- 只用本机 CPU,不花钱。第 1 步 ≤ 1 小时;第 2 步 ≤ 12 小时。超出就停下报告。
- 租 GPU、换更大模型、调用外部 API,都需要负责人另行批准。
- 体检 FAIL 就不做第 2 步。训练出现非有限损失就停。
